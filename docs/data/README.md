# 源泉徴収税額表（月額表）の取込データ

国税庁の年分表を管理画面に取り込むためのファイル置き場です。

## 今回（令和8年分）に使うファイル

| ファイル | 用途 |
| --- | --- |
| お渡しいただいた **`令和8年分_源泉徴収税額表_月額表.xlsx`** のシート「月額表_取込用」 | そのまま Excel で取込（横並び） |
| **`令和8年分_月額表_高額帯.csv`** | 同じ適用開始日で追加取込（長い形式）。740,000円以上と乙欄の低額帯 |

シート「高額帯と注記」だけを Excel ごと取り込むと、加算率が無い階級は**意図的にスキップ**されます。高額帯は上記 CSV か、テンプレートに従って加算率列を足してください。

取込後の検算例: 社保控除後 **442,817** 円・甲・扶養0人 → **19,080** 円。

## 次回以降（毎年）

1. **`月額表_取込用_テンプレート.xlsx`** をコピーし、ファイル名を「令和○年分_…」などに変更する。
2. シート **「月額表_取込用」** に、国税庁の月額表の税額を入力する（**以上・未満** の列は令和8年分の枠のまま。年によって階級が変わる場合は行の追加・削除をする）。
3. 管理画面で Excel を取込（形式: **国税庁の表のまま（横並び）**）。
4. **`月額表_高額帯_テンプレート.csv`** をコピーし、原表の基準額・加算率を入力して **追加取込**（形式: **1行=1マス（長い形式）**）。  
   または Excel テンプレートのシート「高額帯と注記」に基準額と **甲の加算率 / 乙の加算率** を入れ、横並びで取込。
5. 検算ツールと MF クラウドの1名分で突合する。

CSV だけ使う場合は **`月額表_取込用_テンプレート.csv`**（232行の以上・未満枠）に税額を入力しても構いません。

## ファイル一覧

| ファイル | 内容 |
| --- | --- |
| `月額表_取込用_テンプレート.xlsx` | 2シート。メインは階級枠＋空の税額欄。高額帯シートは入力用の表と注記 |
| `月額表_取込用_テンプレート.csv` | 横並び CSV（同上・Excel 不要な場合） |
| `月額表_高額帯_テンプレート.csv` | 高額帯・乙低額帯の長い形式（数値欄は空） |
| `令和8年分_月額表_高額帯.csv` | 令和8年分の高額帯（入力済み・追加取込用） |

管理画面の「テンプレートCSV」リンクからも短いサンプル CSV をダウンロードできます。  
**Excel ひな形（232階級）** は「Excelテンプレート（232階級）」リンクから同じ xlsx を取得できます。

詳細は [毎年更新が必要な法定マスタ 一覧](../annual-master-updates.md) の「源泉徴収税額表（月額表）」を参照してください。
