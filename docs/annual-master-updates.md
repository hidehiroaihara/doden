# 毎年更新が必要な法定マスタ 一覧

給与計算に使う「法律・公的機関が毎年（または不定期に）改定する数値」の棚卸しです。
改定を取り込まないと、**計算は止まらずに古い数値で通ってしまう**ため、毎年この資料を見ながら更新してください。

## 共通ルール

- **過去を塗り替えない。** すべてのマスタは `effective_from`（適用開始日）を持ちます。改定時は
  「新しい適用開始日の行／年分を追加」します。既存行は編集しません。
  こうしておくと、確定済みの過去の給与を再計算しても当時の数値が引けます。
- **出典を必ず残す。** 各画面の「出典・突合メモ」欄に、官報・公表ページと確認日を書いてください。
  例: `国税庁 令和8年分 月額表 2026-01-15 確認`
- **取り込んだら必ず検算する。** 1名分をマネーフォワード クラウド給与や公的な計算ツールと突合します。
  税額表には画面内に検算ツールがあります。
- 公式URLと現在の登録値は `php artisan payroll:rates --urls` / `php artisan payroll:rates --compare` で確認できます。
- この資料はブラウザからも見られます（`/docs`）。パスワードは `.env` の `DOCS_PASSWORD`。
  既定では管理画面ログイン中はパスワード省略可。常に合言葉を求める場合は `DOCS_REQUIRE_PASSWORD_ALWAYS=true`。

## 年間カレンダー（何月に何をするか）

給与計算で迷いやすいのは **「公表月」** と **「何月支給（何月分給与）から新しい数値を使うか」** の違いです。
下表の **作業目安** はマスタを入れる時期、**反映** はその給与計算から使われる目安です。

| 暦月 | 作業目安（この月までに） | 反映（支給・納付の目安） | 更新するマスタ（★＝毎年必須） |
| --- | --- | --- | --- |
| **1月** | 翌年分の月額表を取込・検算 | **1月支給分**の源泉所得税から | ★源泉徴収税額表（月額表）／★賞与の算出率表 |
| **2月** | 協会けんぽの新料率を確認・事業所料率セット作成 | **3月分**（**4月納付**）の健保・介護から | ★健康保険・介護保険料率 |
| **2月** | 翌暦年の祝日を年度設定に登録 | その年度の勤怠・割増区分から | ★年度設定（祝日・所定休日） |
| **3月** | 4月開始の雇用保険率を登録 | **4月1日**以降の賃金から | ★雇用保険料率 |
| **3月** | （2026年〜）子ども・子育て**支援金**料率を健保ブロックに含める | **4月分**以降（制度開始・改定時） | 支援金率（`child_support`・改定年のみ） |
| **4月** | 労災保険率（**改定年のみ**・おおむね3年ごと） | **4月1日**以降 | 労災保険率 |
| **5月** | 市区町村から住民税通知を受領 | — | — |
| **6月** | 従業員ごとに6月〜翌5月の特別徴収額を登録 | **6月支給分**から | ★住民税（特別徴収） |
| **12月** | 翌年の月額表が出始めたら取込準備 | 翌年1月支給から | ★月額表（早めに12月でも可） |
| **随時** | 法改正・上限改定・時限措置のとき | 告示の適用開始日から | 等級表・拠出金率・定額減税・通勤非課税限度 など |

**チェックリスト（毎年この順で見ると漏れにくい）**

1. **12月〜1月** … 月額表・賞与算出率（★）
2. **2月** … 協会けんぽ料率・年度設定の祝日（★）
3. **3〜4月** … 雇用保険（★）・労災（改定年のみ）
4. **5〜6月** … 住民税通知の取込（★）
5. **随時** … 標準報酬等級・拠出金・定額減税・通勤限度

## 1. 源泉徴収税額表（月額表） ★毎年

| 項目 | 内容 |
| --- | --- |
| 作業目安 | **12月〜1月**（国税庁が翌年分を公表してから） |
| 給与への反映 | **1月支給分**から（支給日が属する年分の表を使用） |
| 改定時期 | 毎年12月〜1月に翌年分が公表。**1月支給分から適用** |
| 出典 | 国税庁「給与所得の源泉徴収税額表」 |
| 管理画面 | 基本設定 ＞ 全般 ＞「源泉徴収税額の計算方法」横の **「税額表を管理」** |
| 保存先 | `income_tax_monthly_tables` / `income_tax_monthly_rows` |
| 更新方法 | 画面で「年分を追加（CSV取込）」。テンプレートCSVをダウンロードして表の値を貼り付ける |

社会保険料等控除後の給与等の金額の階級 × 扶養親族等の数から税額を直接引きます。
表の税額には**復興特別所得税が含まれます**。扶養親族等が7人を超える場合の1人あたり控除額（表の注記にある金額）も一緒に登録します。

**未更新のときの挙動:** その支給日をカバーする年分が無いと、後述の「電算機計算の特例」係数へ
自動フォールバックします。画面上部と全般タブに警告が出るので、年が変わったら必ず確認してください。

### 取込ファイルの形式

Excel（.xlsx / .xls）とCSVのどちらでも取り込めます。Excelは全シートを続けて読み込むので、
シートが分かれているブックでもそのままアップロードできます。
取込画面で2つの形式を選べます。通常は **「国税庁の表のまま（横並び）」** を使ってください。

#### 横並び形式（推奨）

列は左から `以上, 未満, 扶養0人 … 扶養7人, 乙, 甲の加算率, 乙の加算率` の13列です（末尾2列は高額帯のみ）。

- 先頭列が金額で始まらない行（見出し・注記）は自動で読み飛ばします
- 「未満」が空欄の階級は、次に大きい階級の下限で自動的に閉じます
- 空欄のマスは登録しません。不足分はあとから追加取込できます
- 同じ適用開始日で何度でも追加取込でき、同じ階級は上書きされます

#### 高額帯（740,000円以上）の注意 ★重要

原表の740,000円以上の欄に載っている金額は**税額ではなく基準額**で、実際の税額は
「基準額 ＋ (給与 − 階級の下限) × 加算率」です。そのまま定額として取り込むと高額者の税額が過少になります。

そのため取込側では、**「未満」が空欄の階級は加算率が無いと取り込みません**（見送った件数を画面で知らせます）。
高額帯を入れるときは、末尾の `甲の加算率` `乙の加算率` に `20.42%` のように入力してください。
甲と乙で加算率が違うため、乙の加算率は甲から流用されません。

令和8年分の高額帯は `docs/data/令和8年分_月額表_高額帯.csv` に用意してあります。
長い形式でそのまま追加取込できます（乙欄の105,000円未満＝3.063% の行も含む）。

**次回以降のひな形**は `docs/data/` にあります（`README.md` 参照）。

- `月額表_取込用_テンプレート.xlsx` … 以上・未満の枠（232行）＋税額入力欄
- `月額表_取込用_テンプレート.csv` … 同上（CSV版）
- `月額表_高額帯_テンプレート.csv` … 740,000円以上を長い形式で入力する枠

#### 長い形式（1行=1マス）

一部のマスだけ直したいときと、高額帯を入れるときに使います。

| 列 | 内容 |
| --- | --- |
| `tax_table` | `kou`（甲欄）/ `otsu`（乙欄） |
| `min_amount` | 社会保険料等控除後の給与等の金額の下限（この額**以上**） |
| `max_amount` | 上限（この額**未満**）。最上位の階級は空欄 |
| `dependents` | 扶養親族等の数。甲欄は 0〜7、乙欄は 0 |
| `tax_amount` | 表の税額（円） |
| `rate` | 率で決まる階級の率、または高額帯の加算率（例 `0.2042`） |
| `deduction` | 率で計算する階級の控除額（円）。無ければ `0` |
| `base_amount` | 高額帯の基準となる税額（円）。`rate` と併用 |
| `excess_over` | 超過額の起点（円）。空欄なら `min_amount` を使う |

### 検算の基準値

令和8年分・甲欄・扶養0人で `440,000円以上443,000円未満` → **19,080円**。
検算ツールに「社保控除後 442,817／扶養0／甲欄」を入れてこの額になれば取込は正しいです。

取り込んだあとは、階級に穴がないかも確認してください。令和8年分は
甲欄が 0円〜3,500,000円超の241階級、乙欄が234階級で、すべて連続します。

## 2. 電算機計算の特例の係数 ☆随時

| 項目 | 内容 |
| --- | --- |
| 作業目安 | 税制改正が公表された月（毎年固定ではない） |
| 給与への反映 | 新しい `effective_from` を付けた行の適用開始日から |
| 改定時期 | 税制改正時（毎年ではない） |
| 出典 | 国税庁「電子計算機等を使用して行う年末調整等」 |
| 管理画面 | なし（Seeder） |
| 保存先 | `income_tax_brackets` |
| 更新方法 | `LegalMasterSeeder::seedIncomeTaxBrackets()` に新しい `effective_from` の行を追加 → `php artisan db:seed --class=LegalMasterSeeder` |

基本設定で「電算機計算の特例を使用する」を選んだ場合、および月額表が未登録のフォールバック時に使われます。

> **注意:** 現在登録されている係数は暫定値です。月額表と比べて税額が大きく出ます
> （例: 社保控除後 442,817円・甲・扶養0人 → 月額表 19,080円 / 特例 48,538円）。
> 特例方式を本番で使う場合は、対象年分の国税庁の係数と必ず突合してください。
> 既定は「税額表（月額表）」です。

## 4. 健康保険・介護保険の保険料率（協会けんぽ） ★毎年

| 項目 | 内容 |
| --- | --- |
| 作業目安 | **2月**（都道府県別料率の公表後。遅くても3月頭まで） |
| 給与への反映 | **3月分**保険料（**4月納付**）から。料率セットの `effective_from` は **3月1日** など |
| 改定時期 | 毎年3月分（4月納付分）から。2月頃に公表 |
| 出典 | 全国健康保険協会「都道府県毎の保険料率」 |
| 管理画面 | 基本設定 ＞ 事業所 ＞ 社会保険（料率セット） |
| 保存先 | `kyokai_kenpo_rates`（全国の参照値） / `insurance_rate_sets`・`insurance_rates`（事業所ごとの適用値） |
| 更新方法 | 参照値は `LegalMasterSeeder::seedKyokaiKenpoRates()` に新 `effective_from` を追加。事業所の適用値は管理画面で新しい料率セットを作成 |

都道府県別の健康保険料率と、全国一律の介護保険料率（40〜64歳）を持ちます。値は**千分率**（‰）で保存します。
組合管掌・国保組合の事業所は、組合から通知された料率を管理画面に直接入力してください。

**子ども・子育て支援金（`child_support`）** も健康保険ブロックの料率セットに含めます。
2026年4月分から従業員負担が始まった年度は、**2〜3月**に支援金率（例: 1.15‰）を健保・介護と一緒にセットし、
「都道府県料率を反映」で標準値が入るか確認してください。

## 10. 住民税（特別徴収税額） ★毎年

| 項目 | 内容 |
| --- | --- |
| 作業目安 | **5月**（通知到着後）〜 **6月支給の計算前** までに登録 |
| 給与への反映 | **6月支給分**から（年度は **6月起点** の `fiscal_year`） |
| 改定時期 | 毎年5月に市区町村から通知。**6月支給分から新年度** |
| 出典 | 各市区町村の特別徴収税額通知書 |
| 管理画面 | 従業員 ＞ 住民税 / 基本設定 ＞ 住民税（市区町村マスタ） |
| 保存先 | `employee_resident_taxes`（`fiscal_year` は起点となる6月の西暦、`month` は暦月） |
| 更新方法 | 通知書の6月〜翌5月の12か月分を従業員ごとに登録 |

法定の率ではなく**従業員ごとの通知額**なので、毎年必ず入れ替えが必要です。
6月分だけ端数が乗った金額になる点に注意してください。入力を忘れると前年度の額が使われます。

## 13. 通勤手当の非課税限度額 ☆随時

## 年間スケジュール早見表（月別・詳細）

| 月 | やること | 給与・社保で効くタイミング |
| --- | --- | --- |
| **1月** | 月額表・賞与算出率の取込漏れがないか最終確認 | 1月支給の所得税 |
| **2月** | 協会けんぽ料率（健保・介護・**支援金**）／**翌年祝日**を年度設定 | 3月分健保（4月納付）／新年度の勤怠 |
| **3月** | **雇用保険**の新率を料率セット登録 | 4月1日以降の賃金 |
| **4月** | 労災率（改定年のみ）／新年度1四半期の運用確認 | 4月以降 |
| **5月** | 住民税通知の受領・一覧化 | — |
| **6月** | 住民税12か月分を従業員登録（**6月分は端数注意**） | 6月支給から |
| **7〜11月** | 定額減税・通勤限度など随時措置があれば対応 | 告示どおり |
| **12月** | 翌年の月額表が出ていれば **早取り** 可能 | 翌年1月支給から |

★＝毎年必須: 月額表、賞与算出率、協会けんぽ（健保・介護）、雇用保険、住民税、年度設定（祝日）。

**用語の整理**

- **○月支給分** … その月に従業員へ振込む給与の計算に使う。
- **○月分保険料** … 社会保険の届・納付の月。健保は **3月分＝4月納付** が年度初めのイメージ。
- **`effective_from`** … システム上「この日付以降の支給日」にこのマスタを使う。上表の反映月と揃える。
