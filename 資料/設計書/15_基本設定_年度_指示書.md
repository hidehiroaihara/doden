## 3. コンポーネント仕様

### 3-1. 年度セレクタ

| 要素 | 内容 |
|---|---|
| 表示 | 「YYYY年」＋▼アイコンのボタン |
| ドロップダウン | 過去年度を含む年度リスト（本キャプチャでは3年分表示）。選択すると同一画面内の全カード・テーブルが選択年度のデータに切り替わる想定 |
| 翌年度作成導線 | 画面最下部に「翌年度(YYYY)を作成する場合は、こちらをクリックしてください。」というテキストリンク。まだ存在しない年度のみ表示されるガイド文言と推測 |

### 3-2. 休日設定カード

| 要素 | 内容 |
|---|---|
| 表示形式 | 月〜日＋祝日の8列テーブル。列見出しは土曜日=青字、日曜日・祝日=赤字で色分け |
| 値 | 各列に「平日」または「所定休日」（本キャプチャでは水曜日が所定休日）を表示。「法定休日」区分も選択肢として存在 |
| 編集モーダル | タイトル「休日設定」。同じ8列テーブルの列ごとに「平日／所定休日／法定休日」のラジオボタン3択。フッターに［更新する］［キャンセル］ |

### 3-3. 独自休日設定カード

| 要素 | 内容 |
|---|---|
| 未登録時表示 | 「独自休日情報がありません。編集ボタンから独自休日情報を登録してください。」という案内文のみ |
| 編集モーダル（空） | タイトル「独自休日設定」。列見出し「休日」「名称」の明細テーブル＋［＋追加］ボタン |
| 編集モーダル（行追加後） | 行ごとに「休日」＝日付ピッカー入力欄（和暦表記併記、例：`1989/1/1, H01.1.1`の形式）、「名称」＝テキスト入力、行右端に🗑削除アイコン。複数行を［＋追加］で追加登録可能 |
| フッター | ［更新する］［キャンセル］ |

### 3-4. 1日の所定労働時間カード

| 要素 | 内容 |
|---|---|
| 表示 | 「1日の所定労働時間」ラベル＋値（時間単位、小数第1位まで） |
| 編集モーダル | ラベル＋数値入力欄（末尾に「時間」の単位表示）の1行フォーム。フッターに［更新する］［キャンセル］ |

### 3-5. 所定労働時間カード

| 要素 | 内容 |
|---|---|
| 表示 | 「所定労働日数(月平均)」「所定労働時間(月平均)」の2行ラベル＋値。カード見出し右に🗑削除アイコンと✏編集アイコンが並ぶ（本設定自体を削除できる＝任意設定という位置づけと推測） |
| 編集モーダル | 「所定労働日数(月平均)」「所定労働時間(月平均)」の2行フォーム（各行末尾に「日」「時間」の単位表示）。フッターに［更新する］［キャンセル］ |

> 📌 **公式サポートサイトでの補足確認**（[「年度」の設定方法](https://biz.moneyforward.com/support/payroll/guide/setting/se15.html)より）：所定労働日数(月平均)・所定労働時間(月平均)は、本来は休日設定に基づいて年間の休日数から自動算出される値だが、就業規則で月あたりの所定労働日数・時間が別途定められている場合は、本カードで直接入力することで**自動算出方式を上書きできる**任意設定である旨が明記されている（カード見出しに🗑削除アイコンが付いていた理由＝上書き設定自体を削除すれば自動算出方式に戻せる、という推測を裏付ける内容）。

### 3-6. 月別日数表

| 行 | 内容 |
|---|---|
| 所定労働日数 | 1月〜12月の月別日数＋右端に年間合計列 |
| 休日数 | 同上 |
| 暦日数 | 同上（1月=31日等の暦通りの日数） |

- 上記「休日設定」の設定結果が月別に自動集計されて表示されるテーブルと推測（要実機確認）

### 3-7. 給与月度（名称未設定）テーブル

| 行 | 内容 |
|---|---|
| 締め日 | 「MM/DD (曜日)」形式。黒文字（リンクなし） |
| 支給日 | 同形式だが青字のリンク表示（クリックで該当期間の[[04_給与計算_設計書]]画面へ遷移する想定、要実機確認） |
| 公開日 | 「MM/DD (曜日)」形式 |
| 所定労働日数 | 期間ごとの日数 |
| ステータス | 「確定済」または「未確定」 |

- 列＝給与月度（支給期間）。本キャプチャでは8期間分が横に並ぶ（年度をまたぐ期間も含む）
- 見出し「給与月度（名称未設定）」＝締め日グループに名称を付けられる仕組みがあると推測（本キャプチャでは未設定のまま）

## 4. データ構造（項目定義）

### 年度マスタ 主要項目

| 区分 | 項目 |
|---|---|
| 休日設定 | 曜日（月〜日）／祝日 × 区分（平日／所定休日／法定休日） |
| 独自休日 | 休日（日付）、名称（複数行登録可） |
| 所定労働時間 | 1日の所定労働時間、所定労働日数(月平均)、所定労働時間(月平均) |
| 月別日数 | 月ごとの所定労働日数／休日数／暦日数（1〜12月＋合計） |
| 給与月度 | 締め日、支給日、公開日、所定労働日数、ステータス（確定済／未確定） |

→ ここで設定する「1日の所定労働時間」「所定労働日数(月平均)」「所定労働時間(月平均)」は、[[04_給与計算_設計書]]の勤怠テーブル「所定労働」欄で参照される値そのものであり、本画面（年度）がそのマスタの実体であることが特定できた（[[05_従業員情報_指示書]]の「業務情報」カードにも同名項目があるが、そちらは従業員個別の値。年度側は事業所単位のデフォルト値という関係と推測、要実機確認）。

## 5. デザインルール

- カード単位の「✏編集」リンク→モーダルというパターンは[[05_従業員情報_指示書]]の従業員詳細パネル（カードごとの編集）と類似するが、本画面はモーダル遷移である点が異なる（詳細パネルはインライン編集）
- モーダルのフッターボタンは金色の［更新する］＋グレーの［キャンセル］で統一。[[04_給与計算_設計書]]・[[05_従業員情報_指示書]]の「更新する」ボタンと同一のボタンコンポーネント
- 表示専用テーブルは「ラベル（左）／値（右）」または「見出し行＋値行」パターンで、既存資料と共通のテーブルスタイル（薄いグレー罫線）を踏襲
- 曜日見出しの色分け（平日=グレー、土曜=青、日曜・祝日=赤）はカレンダーUIの一般的な配色慣習を踏襲したもの

## 6. 拡張・連携ポイント

- 本画面の「所定労働時間」設定が[[04_給与計算_設計書]]の給与計算画面・勤怠テーブルの基礎値になっている。自社実装でも「年度マスタ」を独立テーブルとして持たせ、給与計算・従業員情報双方から参照させる設計が必要
- 「給与月度」テーブルのステータス（確定済／未確定）は[[04_給与計算_設計書]]で確認した「給与の確定を取消」「支給日/締め日/公開日の変更」メニューと連動していると推測される。年度設定側が確定状態のマスタ、給与計算側がその操作画面という役割分担と考えられる（要実機確認）
- 独自休日設定は法定・所定休日とは別に会社固有の休業日（創立記念日等）を登録する仕組みで、[[02_初期設定チュートリアル_設計書]]の休日設定と合わせて年度更新時に毎年見直しが必要な設定項目

## 7. 個人情報保護に関する対応メモ

- 画像に映り込んでいた実在の会社名・ログインユーザー名は、本書はもちろん今後作成するどの資料にも転記していません
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造のみを渡し、実データは渡さないことを推奨します
- 元画像ファイル自体（`基本設定/年度/`フォルダ内）には会社名・ユーザー名が残存しているため、他者と共有する際は取り扱いにご注意ください
