# 基本設定（全体像） 指示書

参照元：マネーフォワード クラウド給与「基本設定」画面
取得資料：画像1枚（「全般」タブ表示時のトップキャプチャ）

> 🔒 **個人情報の取扱いについて**：参照元の画像には実在の会社名・ログインユーザー名が含まれていましたが、本書には一切転記していません。以下は画面構造・項目ラベル・UIコンポーネントのみを抽出したものです。

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | 基本設定（トップ／タブナビゲーション） |
| 目的 | 給与計算に関わる全社共通マスタ（締め日・事業所・支給/控除項目・勤怠項目・保険・年度・明細・システム）を1画面に集約し、タブ切替でそれぞれの設定領域へ遷移する |
| 主要ユーザー | 給与担当者・システム管理者 |
| 表示トリガー | サイドナビ「基本設定」（⚙アイコン） |

## 2. 画面構成（レイアウト）

```
┌──────────────────────────────────────────────────────────┐
│ Header：⚙アイコン＋「基本設定」／🔔／？このページのガイド／事業所／ユーザー   │
├───────────┬──────────────────────────────────────────────┤
│           │ [全般][住民税][事業所][支給項目][控除項目][勤怠項目]      │
│  Side Nav │ [社会保険][労働保険][年度][明細][システム]              │
│  （共通）   │ ─────────────────────────────────────────    │
│           │ セクション1「◯◯」                        ✏編集   │
│           │ ┌────────────────────────────────────────┐   │
│           │ │ 表 or ラベル：値 の2列テーブル               │   │
│           │ └────────────────────────────────────────┘   │
│           │ セクション2「◯◯」                        ✏編集   │
│           │ ┌────────────────────────────────────────┐   │
│           │ │ ...                                     │   │
│           │ └────────────────────────────────────────┘   │
│           │ （以下、セクションが縦に連続）                    │
└───────────┴──────────────────────────────────────────────┘
```

- サイドナビ「基本設定」配下は**独立画面ではなく単一ページ内の横並びタブ**構成。カード一覧やアコーディオンではなく、水平タブ（11個）で切り替える設計
- タブは「全般／住民税／事業所／支給項目／控除項目／勤怠項目／社会保険／労働保険／年度／明細／システム」の11個。選択中タブは下線＋青字でハイライト
- 各タブの中身は「セクション見出し＋右上に✏編集リンク＋表形式の内容」という縦積みブロックの繰り返し構造で統一されている（[[04_給与計算_設計書]]のカード表示パターンと同系統）
- 「編集」リンクはタブ本体を編集モードに変えるのではなく、**モーダルダイアログを開いて個別に更新する**方式（詳細は[[07_基本設定_全般_指示書]]参照）

## 3. コンポーネント仕様

### 3-1. タブナビゲーション

| 要素 | 内容 |
|---|---|
| タブ項目 | 全般／住民税／事業所／支給項目／控除項目／勤怠項目／社会保険／労働保険／年度／明細／システム（合計11） |
| 表示形式 | 横一列のテキストタブ（アイコンなし）。選択中は青字＋下線、非選択はグレー文字 |
| 遷移方式 | クリックで同一ページ内の表示内容が切り替わる想定（URLがタブごとに変わるSPA的挙動か通常のページ遷移かは未確認、要実機確認） |

### 3-2. コンテンツエリア（「全般」タブを例に確認できた共通パターン）

| 要素 | 内容 |
|---|---|
| セクション見出し | 太字テキスト（例：「締め日グループ」「支払口座」等）。セクションごとに区切り線で分離 |
| 編集リンク | 各セクション右上に鉛筆アイコン＋「編集」（青字）。クリックでそのセクション専用のモーダルが開く |
| 本体表示 | セクションの内容に応じて「複数列テーブル」「ラベル：値の2列テーブル」のいずれかで表示 |
| 空状態 | データ未登録のセクションは「〇〇情報がありません。編集ボタンから登録してください」という案内文を表示 |

→ 従業員情報画面（[[05_従業員情報_指示書]]）の「カード単位インライン編集」とは異なり、基本設定は「セクション単位でモーダルを開いて編集」という設計。編集の単位はどちらも“セクション／カード”だが、編集UIの実現方法（インライン展開 vs モーダル）が画面によって異なる点に注意。

## 4. データ構造（項目定義）

本画面（トップ）自体は表示専用の入れ物であり、直接のデータ項目は持たない。配下タブごとの詳細項目は各タブの指示書（[[07_基本設定_全般_指示書]]、[[08_基本設定_事業所_指示書]]、以降作成予定の各タブ指示書）を参照。

| 区分 | 内容 |
|---|---|
| タブ一覧マスタ | タブ名・表示順・遷移先を持つナビゲーション定義（自社実装でも設定メニュー定義をマスタ化し、タブ側はこれを元にレンダリングする設計を推奨） |

## 5. デザインルール

- タブUIは[[05_従業員情報_指示書]]の「詳細パネル内5タブ（一般情報／給与情報等）」と見た目・挙動が共通（下線ハイライト方式のテキストタブ）。自社実装でも同一のタブコンポーネントを使い回す設計を推奨
- セクション見出し＋右上「編集」リンクの配置は[[04_給与計算_設計書]]・[[05_従業員情報_指示書]]の「カード右上✏編集」と共通のパターン言語
- 表示専用テーブルは「ラベル（左）／値（右）」または「複数列見出し＋データ行」の2系統に統一（[[01_ホーム画面_設計書]]〜[[05_従業員情報_指示書]]と共通のテーブルスタイルを踏襲）

---

## 6. 拡張・連携ポイント

- 基本設定配下の11タブは、給与計算・従業員情報など他画面で選択肢として使われるマスタ（部門・職種・契約種別・締め日グループ等）の**一次登録場所**になっていると推測される。実際、「全般」タブの「集計区分設定（部門）」「集計区分設定（職種）」は[[04_給与計算_設計書]]の絞り込みフィルタ（全部門／全職種）の選択肢元と一致することを確認済み
- 自社実装でも「設定」領域を本画面同様にタブ集約型のハブ画面として設計し、各タブ配下のマスタ編集機能から他画面のドロップダウン選択肢を動的に参照させる構成を推奨

---

## 7. 個人情報保護に関する対応メモ

- 画像内の実在の会社名・ログインユーザー名は、本書はもちろん今後作成するどの資料にも転記していません
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造のみを渡し、実データは渡さないことを推奨します
- 元画像ファイル自体（`基本設定/`フォルダ内）には会社名・ユーザー名が残存しているため、他者と共有する際は取り扱いにご注意ください
