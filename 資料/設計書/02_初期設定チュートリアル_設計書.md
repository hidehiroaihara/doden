# 初期設定チュートリアル 設計書

参照元：マネーフォワード クラウド給与「初期設定チュートリアル」（ホーム画面「はじめに」カードからの遷移先）
対象画面数：7画面（ウィザード形式）

1. はじめに（事業所情報入力）
2. 締め日・支給日を設定
3. 休日を設定
4. 所定労働日数・所定労働時間を設定
5. 所得税計算を設定
6. 労働保険を設定
7. 社会保険を設定

---

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | 初期設定チュートリアル（ウィザード） |
| 目的 | 給与計算に必要な事業所マスタ情報を、迷わず順番に入力させる |
| 主要ユーザー | 初回導入時の労務・人事担当者（管理者） |
| 表示トリガー | ホーム画面「はじめに」カードの「初期設定チュートリアル」リンク |
| 完了後の遷移 | 最終ステップの「初期設定を完了する」ボタン押下でホームへ戻る想定 |

---

## 2. 画面構成（共通レイアウト）

```
┌──────────────────────────────────────────────────────┐
│ Header：ロゴ＋「初期設定チュートリアル」ラベル                    │
├───────────────┬──────────────────────────────────────┤
│ [はじめに]バッジ  │                                        │
│ (縮小表示・アイコン)│        ステップタイトル（青・中央寄せ）           │
│                │        説明文（グレー・中央寄せ、2〜3行）          │
│ ステップ一覧      │                                        │
│  ✓ 締め日・支給日   │  ── フォームセクション ──                   │
│  ● 休日          │   見出し                                │
│  ○ 所定労働日数    │   ラベル｜入力欄（＋必須バッジ）              │
│  ○ 所得税計算     │   [+説明を見る] アコーディオン               │
│  ○ 労働保険       │                                        │
│  ○ 社会保険       │                                        │
│                │                                        │
│ [広告バナー]      │        [前へ]        [次へ]              │
│ (スコープ外)      │                                        │
└───────────────┴──────────────────────────────────────┘
```

- 左カラム：ウィザードナビ（固定幅）。上部に「はじめに」への戻りバッジ、その下にステップリスト
- 右カラム：現在ステップのフォームコンテンツ（1カラム、縦スクロール）
- フッター：常に画面下部に「前へ／次へ」（最終ステップのみ「初期設定を完了する」）
- 左カラム下部の広告バナー（導入・運用マニュアル）は**スコープ外**（ホーム画面の右カラムと同様、社内ツールでは不要）

## 3. 共通コンポーネント仕様

### 3-1. ウィザードナビ（ステップリスト）

| 状態 | 表示 | 文字色 |
|---|---|---|
| 完了 | 緑の丸チェックアイコン | グレー（薄） |
| 現在地 | 青い塗りつぶしラジオ | 青・太字 |
| 未着手 | 白抜きラジオ | グレー |

- ステップ名クリックで該当ステップへ直接ジャンプ可能（完了済み・現在地は移動可、未着手は要検討）
- 「はじめに」は最上部に独立したバッジとして常時表示（ステップ番号には含まれない導入ページ扱い）

> 📌 **公式サポートサイトでの補足確認**（[チュートリアルによる初期設定の方法](https://biz.moneyforward.com/support/payroll/guide/employee-management/em06.html)より）：「完了したステップにはチェックマークが反映され、クリックで任意のステップへ移動可能」と明記されている。上記「未着手は要検討」の論点について、公式記事の書きぶりからは未着手ステップも含めて任意のステップへ移動できる可能性が高いが、画面上でどう視覚表現されるか（非活性表示の有無等）までは記事に明記されておらず、依然として実機確認が望ましい。

### 3-2. ステップコンテンツ共通構造

| 要素 | 内容 |
|---|---|
| タイトル | 青文字・中央寄せ・大きめフォント（例：「締め日・支給日を設定」） |
| リード文 | グレー・中央寄せ、2〜3行でこのステップの目的を説明 |
| セクション見出し | 黒文字・左寄せ（例：「締め日グループ情報」） |
| 入力フィールド | ラベル（左）＋入力欄（右）の横並び。必須項目は赤バッジ「必須」を付与 |
| 説明アコーディオン | 「＋説明を見る」／「－説明を閉じる」でグレー小文字の補足説明を開閉 |
| フッターボタン | 「前へ」（グレー・非活性風）／「次へ」（オレンジ〜ゴールド、活性色）。最終ステップのみ「初期設定を完了する」 |

### 3-3. 特殊コンポーネント

- **表形式入力**（休日設定、月別所定労働日数）：曜日／月を行、ラジオボタンや算出値を列に配置
- **繰り返しブロック＋追加ボタン**（締め日グループ、独自休日、健康保険証イメージ等）：「＋追加」ボタンでブロックを複製、右上に削除（ゴミ箱）アイコン
- **外部サイト埋め込み参照**（労働保険ステップの厚労省ページキャプチャ）：外部サイトの全体スクリーンショットを説明として埋め込んでいる。自社実装では**埋め込み再現はせず、「外部サイトで確認する」リンクを別タブで開く形に置き換える**ことを推奨（後述6章）
- **自動計算値の表示**（所定労働日数・時間）：他画面の設定値から自動算出され、編集不可の欄と、手入力に切り替え可能な欄（チェックボックスで「自動計算を使わず、手入力で設定する」）が混在

## 4. ステップ別データ項目

### Step 0：はじめに（事業所情報）

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 事業所名 | text | ○ | |
| 事業所名フリガナ | text | - | |
| 郵便番号 | text | - | |
| 都道府県 | select | ○ | |
| 住所1 | text | - | |
| 住所1カナ | text | - | |
| 住所2 | text | - | |
| 住所2カナ | text | - | |
| 電話番号 | text | - | |
| 事業主役職名 | text | - | |
| 事業主名 | text | - | |

### Step 1：締め日・支給日を設定

「締め日グループ」を単位として繰り返し登録可能。

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 名称 | text | ○ | 締め日グループの名称 |
| 締め日 | select | - | 例：末日／15日 等 |
| 支給日 | select | - | 例：翌月末日 等 |
| 銀行休業日の場合の扱い | radio | - | 前営業日／翌営業日／手動で変更 |

→「＋追加」で締め日グループを複数作成可能（部署・雇用形態ごとに締め日が異なるケースに対応）

### Step 2：休日を設定

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 曜日別区分（月〜日） | radio×7 | ○ | 平日／所定休日／法定休日 の3択 |
| 祝日区分 | radio | ○ | 平日／所定休日／法定休日 |
| 独自休日（繰り返し） | date + text | - | 休日（日付）＋名称。「＋追加」で複数登録 |

### Step 3：所定労働日数・所定労働時間を設定

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 1ヶ月の所定労働日数（1〜12月） | 自動算出（表示のみ） | - | Step2の休日設定から自動計算、編集不可 |
| 1日の所定労働時間 | number | - | 時間単位、法定8時間以内 |
| 自動計算を使わず手入力で設定するか | checkbox | - | ONで下記2項目が手入力可能に |
| 所定労働日数（月平均） | number | - | 自動計算 or 手入力 |
| 所定労働時間（月平均） | number | - | 所定労働日数×1日の所定労働時間で自動計算 or 手入力 |

### Step 4：所得税計算を設定

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 源泉徴収税額の計算方法 | radio | ○ | 「税額表（月額表）を使用する」／「電算機計算の特例を使用する」 |

補足として国税庁の「給与所得の源泉徴収税額表」画像を参考表示（自社実装では画像 or PDFリンクでの参照を想定）。

### Step 5：労働保険を設定

**労災保険**

| 加入状況 | radio | ○ | 加入している／加入していない |
| 管轄（労働基準監督署） | text | - | |
| 労働保険番号 | text（分割入力） | - | 府県／管轄／基幹番号／枝番号の複数欄に分割 |
| 具体的な業種又は作業の内容 | text | - | |
| 労災保険料率用業種 | select | - | |

**雇用保険**

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 加入状況 | radio | ○ | 加入している／加入していない |
| 管轄（公共職業安定所） | text | - | |
| 事業所番号 | text（分割入力） | - | |
| 雇用保険料率用業種 | select | - | |

※ページ中に「厚生労働省 管轄区域検索ページ」の外部サイトが全体スクリーンショットとして埋め込まれている（労災・雇用保険それぞれ1回）。これは設定作業の補助情報であり、自社実装では別タブリンクへの置き換えを推奨（6章参照）。

### Step 6：社会保険を設定

**健康保険・介護保険**

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 加入状況 | radio | ○ | 加入している／加入していない |
| 健康保険の種類 | radio | - | 協会管掌事業所／組合管掌事業所／国民健康保険組合 |
| 管轄 | text（自動反映） | - | Step0の都道府県から自動反映 |
| 事業所整理記号 | text | - | 被保険者証で確認できる旨の説明＋証券画像サンプルを表示 |

**厚生年金保険**

| フィールド | 型 | 必須 | 備考 |
|---|---|---|---|
| 加入状況 | radio | ○ | 加入している／加入していない |
| 管轄（年金事務所） | text | - | |
| 事業所番号 | text | - | |
| 事業所整理記号 | text（分割入力） | - | 前半／後半の2欄 |

## 5. デザインルール

### 5-1. 配色

| 用途 | 色味の目安 |
|---|---|
| ステップタイトル | ブルー（ホーム画面のリンク色と同系統） |
| 完了チェックアイコン | グリーン |
| 現在地ラジオ／強調文字 | ブルー |
| 必須バッジ | 赤（背景赤・白文字） |
| 「次へ」ボタン | オレンジ〜ゴールド系（активные状態を強調） |
| 「前へ」ボタン | グレー（相対的に目立たせない） |
| フォーム罫線・背景 | 薄いグレー罫線／白背景 |

### 5-2. レイアウトルール

- 左ナビは常時表示・固定幅、右コンテンツのみスクロール
- 1ステップ1画面の原則（複数トピックを1画面に詰め込まない。休日設定のように関連項目が多い場合のみ「休日設定」「独自休日設定」のように画面内でセクション分割）
- 入力フィールドは「ラベル：入力欄」の横並び統一、フィールド幅は画面内で統一
- 説明文はデフォルト非表示（アコーディオン）にし、画面の情報密度を抑える設計を踏襲

### 5-3. インタラクションルール

- 「次へ」は入力必須項目が揃うまで非活性、もしくは未入力時にバリデーションエラーを表示
- 左ナビのステップクリックで直接移動可能（完了ステップへの戻り編集を許可）
- 自動計算項目（所定労働日数等）はチェックボックスで手入力モードに切替できるパターンを踏襲

> 📌 **公式サポートサイトでの補足確認**（[チュートリアルによる初期設定の方法](https://biz.moneyforward.com/support/payroll/guide/employee-management/em06.html)より）：「各ステップで『前へ』や『次へ』をクリックすることで保存が可能」と明記されており、各ステップ単位で段階的に保存される仕様であることが確認できた（最終ステップまで到達しないと保存されない、という設計ではない）。

## 6. 除外・置き換え項目（スコープ外／要方針決定）

| 項目 | 対応方針 |
|---|---|
| 左ナビ下部の広告バナー（導入・運用マニュアルの案内） | 実装不要 |
| 厚労省サイトの全体スクリーンショット埋め込み（労働保険ステップ） | 埋め込み再現はせず、「厚生労働省サイトで確認する」外部リンク（別タブ）に置き換える |
| 源泉徴収税額表の画像埋め込み | 自社の税額表データ・PDFリンクへの差し替えを想定 |
| 健康保険被保険者証のサンプル画像 | 説明用の記入例画像として自社デザインで作り直すか、テキスト説明のみに簡略化するか要検討 |

> 📌 **公式サポートサイトでの補足確認**（[チュートリアルによる初期設定の方法](https://biz.moneyforward.com/support/payroll/guide/employee-management/em06.html)より）：「初期設定チュートリアルでは、すべての項目を設定できません」と明記されており、チュートリアル完了後も詳細な設定は別途「基本設定」画面（サイドナビ「基本設定」配下、[[01_ホーム画面_設計書]]3-2章のメニュー項目6に相当）で行う必要がある。自社実装でも、ウィザードは初期導入時の最小設定に限定し、詳細設定は別の設定画面群に委ねる設計方針を踏襲するのが妥当。

## 7. 次アクション（別AIへの実装指示のたたき台）

1. ウィザード共通コンポーネント（左ナビ＋右コンテンツ＋フッターボタン）を1つ作り、ステップごとにフォーム部分のみ差し替える構造にする
2. ステップの状態管理（完了／現在地／未着手）をステータスとして持たせ、左ナビの表示切り替えに利用
3. 4章の項目定義を元に、各ステップの入力フォームとバリデーションルールを実装
4. 外部サイト参照（厚労省リンク等）はiframe埋め込みではなく別タブ遷移のリンクとして実装
5. 自動計算項目（所定労働日数・時間）は、休日設定の入力結果から計算するロジックを別途設計する
