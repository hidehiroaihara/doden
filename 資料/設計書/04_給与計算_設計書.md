# 給与計算 設計書

参照元：マネーフォワード クラウド給与「給与計算」画面
取得資料：画像2枚＋DOM構造（index.html）

> 🔒 **個人情報の取扱いについて**：参照元の画像・HTMLには実在の従業員氏名・従業員番号・給与金額が含まれていましたが、本設計書には一切転記していません。以下は画面構造・項目ラベル・UIコンポーネントのみを抽出したものです。

---

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | 給与計算 |
| 目的 | 支給期間ごとに、対象従業員の給与を一覧から選択し、支給・控除・勤怠の内訳を確認／修正する |
| 主要ユーザー | 給与担当者 |
| 表示トリガー | サイドナビ「給与計算」 |

## 3. コンポーネント仕様

### 3-1. ヘッダーコントロール群

| 要素 | 内容 |
|---|---|
| 支給期間セレクタ | 「YYYY年MM月DD日支給（YYYY年MM月DD日〆）」表示＋ドロップダウンで他期間へ切替。ドロップダウン内は年単位のページング（前年／翌年）＋期間リスト（確定済み期間は「finalized」状態で視覚的に区別） |
| 対象者数 | 当期間の対象従業員数を表示。ホバー/クリックで「入社者数：n　退職者数：n」をツールチップ表示 |
| メモ | 期間単位のメモを入力できるドロップダウン（テキストエリア、「記載内容は従業員の給与明細には表示されません」の注記付き） |
| 振込業務 | ドロップダウンメニュー：給与振込のFBデータ出力／給与振込一覧表で確認／住民税のFBデータ出力／住民税徴収額一覧表で確認 |
| メニュー | ドロップダウンメニュー：締め日/支給日/公開日の変更／支給・控除・勤怠CSVダウンロード／給与を修正する／給与の確定を取消（いずれもモーダル遷移、詳細画面は8章「未取得」参照） |

> 📌 **公式サポートサイトでの補足確認**（[「給与計算」画面の使い方](https://biz.moneyforward.com/support/payroll/guide/payroll/payr06.html)より）：
> - 本キャプチャのヘッダー要素（支給期間セレクタ／対象者数／メモ／振込業務／メニュー）に加えて、公式ガイドには「表示切替」「前月比較」「確定処理」ボタンの存在が記載されている。「表示切替」では「一括入力モード」（支給・控除・勤怠項目を一括で入力できるモード）と「支給控除一覧表形式」（一覧確認用。印刷は非対応）を切り替えられる。本キャプチャにこれらのボタンが写っていない理由は不明（権限・契約プラン・キャプチャ範囲の違い等の可能性があり、要実機確認）。
> - 「メニュー」配下には、本キャプチャで確認済みの4項目に加えて、「支給/控除/勤怠CSVインポート」「他社ソフトからのCSVインポート」「一括で自動計算に戻す」（手入力・取込データを一括で自動計算結果に戻す機能）が存在することが確認できた。
> - 備考欄は最大1000文字まで入力可能で、内容は給与明細に反映される（本キャプチャの「備考：[__________________]」欄に対応）。

### 3-2. 絞り込みフィルタ

| フィルタ | 種別 | 選択肢の性質 |
|---|---|---|
| 全社／拠点 | ドロップダウン | 事業所配下のグループ（支店等）をマスタから選択。「全社」がデフォルト |
| 全部門 | ドロップダウン | 部門マスタから選択 |
| 全職種 | ドロップダウン | 職種マスタから選択（本キャプチャでは「全職種」のみで職種未登録） |
| 全契約種別 | ドロップダウン | システム標準の契約種別：役員／使用人兼務役員／正社員／契約社員／嘱託社員／パート／アルバイト／派遣社員／その他 |
| 修正した従業員のみ表示 | チェックボックス | ONで一覧を絞り込み |

→ 拠点・部門は「グループ」「部門」という2階層のマスタで管理されている（自社の組織階層設計時に参考にできるポイント）。

### 3-3. 従業員リスト

| 要素 | 内容 |
|---|---|
| 検索ボックス | プレースホルダー「従業員番号 / 氏名」でリアルタイム絞り込み |
| リスト項目 | 「従業員番号 / 氏名」表記。選択中の行はハイライト背景 |
| 状態アイコン | 行右端にチェックアイコン（＝計算済み／確認済みを示すステータスと推測。一部の行にはアイコンが付かないケースあり＝未計算 or 対象外の可能性、要実機確認） |
| リスト自体 | 固定高さ・内部スクロール（左パネルのみ独立してスクロールする設計） |

> 📌 **公式サポートサイトでの補足確認**（[「給与計算」画面の使い方](https://biz.moneyforward.com/support/payroll/guide/payroll/payr06.html)より）：チェックアイコンには少なくとも2種類の意味があることが確認できた。①従業員リスト行に表示される「確認済」チェック：担当者が内容確認済みであることを手動でチェックし、確認済み従業員と未確認の従業員を判別するためのもの。②支給年月日の右側に表示されるチェック：その支給期間の給与計算が確定済みであることを示す。本キャプチャの「一部の行にアイコンが付かない」という観察は、①の「未確認」状態に該当する可能性がある（記事上での一対一対応の明記はなく、推測の域を出ないため注意）。

### 3-4. 給与明細（3カラムテーブル）

| カラム | 内容 |
|---|---|
| 支給 | 支給項目（例：基本給、通勤手当、役職手当 等）を行ごとに表示し、最下部に「合計」行 |
| 控除 | 控除項目（例：健康保険料、介護保険料、子ども・子育て拠出金、厚生年金保険料、雇用保険料、所得税、住民税 等）を行ごとに表示し、最下部に「合計」行 |
| 差引合計 | 「振込支給額」＋最下部に「差引支給合計」行 |

- 各カラムは項目名（左）＋金額（右揃え・数値）の2列テーブル
- 表示される支給・控除項目は従業員の契約条件（雇用保険のみ／社会保険あり等）によって行数・項目が変動する（＝動的に項目が増減するテーブル設計が必要）
- 3カラムの下に「備考」欄（フリーテキスト、1行入力）

> 📌 **公式サポートサイトでの補足確認**（[「給与計算」画面の使い方](https://biz.moneyforward.com/support/payroll/guide/payroll/payr06.html)より）：給与確定後も「給与を修正する」機能で従業員単位の再修正が可能だが、「社会保険料の会社負担分は修正ができません」（確定時点の従業員情報は変更不可のため）という制約がある。控除カラムの社会保険料関連項目（健康保険料・介護保険料・厚生年金保険料等）は、この制約の対象になり得る点に留意。

### 3-5. 勤怠テーブル（4象限）

| 象限 | 項目例 |
|---|---|
| 所定労働（左上） | 1日の所定労働時間／所定労働日数(当月)／所定労働日数(月平均)／所定労働時間(当月)／所定労働時間(月平均) |
| 出欠勤（右上） | 出勤日数（平日）／出勤日数（合算） |
| 実働時間（左下） | 所定時間（平日）／深夜所定時間（平日）等 |
| 休暇（右下） | （本キャプチャでは空欄。有給等の項目が入る想定） |

- 2×2の見出し行（背景グレー、colspan結合）の下に、左右2列×複数行の項目テーブルという構造
- 値が無い項目は空欄表示（「−」等のプレースホルダーは使用しない、ホーム画面・メンバー一覧と共通の設計方針）

> 📌 **公式サポートサイトでの補足確認**（[クラウド勤怠で集計した「残業」や「法定外」をもとに給与計算を行う方法](https://biz.moneyforward.com/support/payroll/guide/payroll/payr11.html)、[マネーフォワード クラウド勤怠で集計した「労働時間」や「有給休暇時間」をもとに給与計算を行う方法](https://biz.moneyforward.com/support/payroll/guide/payroll/payr12.html)より）：クラウド勤怠と連携している場合、勤怠テーブルには「所定時間（平日）（内）」「残業（平日）（内）」「法定外時間（平日）（内）」「法定外時間（法定休日）（内）」「深夜（平日）（内）」「休暇みなし時間」「控除繰越限度超過時間」（フレックスタイム制向け）等の項目が並ぶことが確認できた。特に「休暇」象限（本キャプチャでは空欄）には、有給休暇取得時間を示す「休暇みなし時間」が入る想定で、この時間数をもとに時給制従業員向けの有給休暇手当等が自動計算される。各項目は「基本設定」→「勤怠項目」で有効化する必要がある。

## 4. データ構造（項目定義）

### 給与明細項目マスタ（例）

| 区分 | 項目名例 | 備考 |
|---|---|---|
| 支給 | 基本給、通勤手当（非課税）、役職手当 | 従業員ごとに表示項目が変動 |
| 控除 | 健康保険料、介護保険料、厚生年金保険料、雇用保険料、子ども・子育て拠出金、所得税、住民税 | 加入している保険・条件により行が増減 |
| 差引 | 振込支給額、差引支給合計 | 支給合計－控除合計で自動計算される想定 |

### 勤怠項目マスタ（例）

| 区分 | 項目名例 |
|---|---|
| 所定労働 | 1日の所定労働時間、所定労働日数(当月/月平均)、所定労働時間(当月/月平均) |
| 出欠勤 | 出勤日数（平日）、出勤日数（合算） |
| 実働時間 | 所定時間（平日）、深夜所定時間（平日） |
| 休暇 | （本キャプチャでは項目未確認。公式ガイドでは「休暇みなし時間」が該当項目として確認できた。詳細は3-5節の補足確認欄参照） |

→ [[02_初期設定チュートリアル_設計書]]で設定した「所定労働日数・所定労働時間」の値が、この画面の「所定労働」欄に反映される連動関係になっている。初期設定マスタと給与計算画面のデータ連携を設計時に踏襲する必要あり。

## 5. デザインルール

- ヘッダーのボタン群（メモ／振込業務／メニュー）は共通のドロップダウンボタンコンポーネントを使用（薄いグレー〜カーキ背景、右端に▼アイコン）
- 選択中の従業員名はブルーのリンク調文字＋人物アイコン
- テーブルは「項目名（左）／数値（右揃え）」の2列パターンで統一し、[[01_ホーム画面_設計書]]・[[03_メンバー追加_設計書]]と共通のテーブルスタイル（薄いグレー罫線、合計行のみ背景をやや強調）を踏襲
- 3カラムの給与内訳テーブルは、カラム幅を均等割りにし、スマホ等の狭い画面では縦積みに変更するレスポンシブ対応を推奨（本キャプチャはPC画面のみのため、モバイル時の挙動は別途要検討）
- 左の従業員リストは検索性を重視し、常時フィルタ＋検索ボックスを画面上部に固定表示する設計を踏襲

---

## 6. 拡張・連携ポイント

- 支給・控除項目は固定ではなく、事業所ごとにカスタム項目を追加できるマスタ管理が背後にあると推測される（自社実装でも「支給項目マスタ」「控除項目マスタ」をテーブルとして持たせ、画面側は動的にレンダリングする設計を推奨）
- 勤怠データ（出勤日数・実働時間等）は本来「勤怠連携」機能から自動反映される項目だが、[[01_ホーム画面_設計書]]の方針により本プロジェクトでは対象外。自社勤怠システム側では、この給与計算画面に相当する機能から自社の勤怠実績テーブルを直接参照する設計になる想定

---

## 7. 個人情報保護に関する対応メモ

- 画像内の実名（従業員氏名）・従業員番号・金額は、この設計書はもちろん、今後作成するどの資料にも転記していません
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造のみを渡し、実データは渡さないことを推奨します
- 元画像・HTMLファイル自体（`給与計算/`フォルダ内）には個人情報が残存しているため、他者と共有する際は取り扱いにご注意ください

## 8. 未取得・要追加確認事項

| 項目 | 内容 |
|---|---|
| 「締め日/支給日/公開日の変更」モーダル | 依然未確認。カテゴリページ（[給与・賞与計算](https://biz.moneyforward.com/support/payroll/guide/payroll)／[支払業務](https://biz.moneyforward.com/support/payroll/guide/payment-operations)）配下に、モーダルの画面項目・入力形式を個別解説する記事は見つからなかった。実機確認が必要。 |

| 「給与を修正する」画面 | 一部解決。[「給与計算」画面の使い方](https://biz.moneyforward.com/support/payroll/guide/payroll/payr06.html)より：確定後の修正は従業員単位でメニューから「給与を修正する」を選択して行う。ただし「社会保険料の会社負担分は修正ができません」（確定時点の従業員情報は変更不可のため）という制約がある。個別修正フォームの具体的な入力項目・レイアウトは記事に記載がなく、依然未確認。 |
