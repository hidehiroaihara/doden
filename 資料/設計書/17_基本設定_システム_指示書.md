# 基本設定（システム） 指示書

参照元：マネーフォワード クラウド給与「基本設定」画面／タブ「システム」
取得資料：画像1枚＋DOM構造（index.html、「支給控除の表示パターンを設定」追加モーダルのフォームHTML）

> 🔒 **個人情報の取扱いについて**：参照元の画像・HTMLには実在の会社名・ログインユーザー名が含まれていましたが、本書には一切転記していません。以下は画面構造・項目ラベル・UIコンポーネントのみを抽出したものです。なお本画面自体に従業員個人の氏名・住所等は表示されません。

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | 基本設定 - システム |
| 目的 | 「支給控除一覧表」「支給控除一覧表(部門別)」「支給控除一覧表(賞与)」「支給控除一覧表(賞与部門別)」「賃金台帳」の各帳票について、表示する項目セット（表示パターン）を複数登録・管理する |

## 3. コンポーネント仕様

### 3-1. 表示パターン一覧（帳票種別ごと）

| 要素 | 内容 |
|---|---|
| セクション見出し | 帳票名（支給控除一覧表／支給控除一覧表(部門別)／支給控除一覧表(賞与)／支給控除一覧表(賞与部門別)／賃金台帳） |
| テーブル | 「表示パターン名」列＋操作用の空列2つ（編集・削除等のアイコンが入る想定、本キャプチャでは未登録のため確認不可） |
| ［＋追加］ | クリックで当該帳票用の「表示パターンを設定」モーダルを開く。賞与未確定時は非表示 |

### 3-2. 「支給控除の表示パターンを設定」モーダル（DOMから復元）

| 要素 | 内容 |
|---|---|
| タイトル | 「支給控除の表示パターンを設定」 |
| 説明文 | 「支給控除に表示する項目を設定します。設定は給与担当者ごとに保持されます。基本設定で無効に設定されている項目は、グレーアウトで表示されます。」 |
| 表示パターン名 | テキスト入力欄（必須と推測） |
| オプション | チェックボックス「差引支給合計が0円の従業員も含める」 |
| 項目チェックボックス群 | カテゴリ見出し行＋チェックボックス2〜3列×複数行のテーブルが、カテゴリ単位で縦に11セクション並ぶ（3-3参照） |
| フッター | ［保存］ボタン（金色、フォーム送信） |

- モーダル本体はスクロール可能な`scroll-modal-content`として実装されており、項目数が多いため内部スクロールする設計
- 各カテゴリ見出し行の先頭に「すべて選択」トグル用チェックボックスがあり、カテゴリ単位で一括ON/OFFできる（`toggle_select_all_〜`という命名規則のJSフック）

### 3-3. 項目チェックボックス群のカテゴリ構成

| カテゴリ | 主な項目例 |
|---|---|
| 基本情報 | 従業員番号、生年月日 |
| 在籍情報 | 入社年月日、退職年月日 |

| 支給項目 | [[16_基本設定_明細_指示書]]の支給項目マスタと同一の項目群（基本給、役職手当、通勤手当/課税・非課等） |
| 控除項目 | 同じく[[16_基本設定_明細_指示書]]の控除項目マスタと同一の項目群（健康保険料、厚生年金保険料、雇用保険料、所得税、住民税、定額減税等） |
| 支給関連の差引合計項目 | 課税支給合計、非課税支給合計、支給合計、労保対象合計、社保対象合計(金銭/現物)、固定賃金合計、役員報酬合計、割増基礎合計、控除基礎合計 等 |
| 控除関連の差引合計項目 | 社会保険料合計、控除合計 |

| その他 | 扶養人数、税額表、健保標準報酬、厚年標準報酬 |
| 会社負担分 | 健康保険料(会社)、介護保険料(会社)、厚生年金保険料(会社)、雇用保険料(会社)、労災保険料(会社)、一般拠出金(会社) 等 |

- 各行は「チェックボックス＋項目名」の組を1〜3個横並びにした複数列テーブル（3列×複数行が基本形）

## 5. デザインルール

- カテゴリ見出し＋一括選択チェックボックスというパターンは本書で確認した範囲では本画面が初出。[[16_基本設定_明細_指示書]]の明細テンプレートは項目を縦1列でチェックする形式だったのに対し、本画面は横3列でコンパクトに項目を並べる形式であり、同じ「項目セットのカスタマイズ」という目的に対し2種類のUIパターンが併存している（自社実装では項目数に応じてどちらの形式を採るか統一方針を検討する必要あり）
- 基本設定で無効化されている項目はグレーアウト表示という仕様は[[16_基本設定_明細_指示書]]の明細テンプレートと共通のルール
- モーダルのフッターは金色の実行ボタン（本画面では［保存］、他画面では［更新する］）のみでキャンセルボタンがない点が[[15_基本設定_年度_指示書]]・[[16_基本設定_明細_指示書]]の各モーダル（［更新する］［キャンセル］の2ボタン構成）と異なる（右上の✕アイコンでのみ閉じる設計と推測、要実機確認）

## 6. 拡張・連携ポイント

- 「支給控除一覧表」「賃金台帳」等の帳票出力機能自体は本担当の3画面には含まれないため未取得だが、本画面がそれらの帳票の“列カスタマイズ”を担う設定画面であることが分かった。自社実装で帳票機能を作る場合、出力ロジックと表示パターン設定を分離し、本画面のようなマスタ管理画面から表示項目を都度参照する設計が望ましい
- 「表示パターン名」の管理主体は「給与担当者ごとに保持されます」と明記されており、[[16_基本設定_明細_指示書]]の給与明細テンプレート（事業所単位で締め日グループに紐付く想定）とは異なり、本画面のパターンはユーザー単位の個人設定である点が設計上の重要な違い
- 賞与系パターンが「賞与確定済」を条件に活性化される制御は、[[04_給与計算_設計書]]で確認した「給与の確定」ステータスと同様の考え方（確定という状態がその後の機能を解放するトリガーになる）が帳票設定にも及んでいることを示す

## 7. 個人情報保護に関する対応メモ

- 画像・HTMLに含まれていた実在の会社名・ログインユーザー名は、本書はもちろん今後作成するどの資料にも転記していません
- HTML内のCSRFトークン（`authenticity_token`）等のシステム内部値も転記していません
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造のみを渡し、実データは渡さないことを推奨します
- 元画像・HTMLファイル自体（`基本設定/システム/`フォルダ内）には会社名・ユーザー名が残存しているため、他者と共有する際は取り扱いにご注意ください
