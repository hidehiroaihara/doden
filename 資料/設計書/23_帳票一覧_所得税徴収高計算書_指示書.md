## 3. コンポーネント仕様

### 3-1. 期間選択

| 要素 | 内容 |
|---|---|
| 年ドロップダウン | 対象年を選択 |
| 月ドロップダウン | 対象月（支払月）を選択。1〜12月から選択する通常のプルダウンと推測 |

→ 所得税の源泉徴収は原則「徴収した月の翌月10日まで」に毎月納付する必要があるため、月単位で選択・出力する設計になっている（[[24_帳票一覧_所得税徴収高計算書_納期特例_指示書]]との最大の違い。4章参照）。

### 3-2. 帳票本体（国税庁様式再現エリア）

国税庁「給与所得・退職所得等の所得税徴収高計算書（一般用）」の3枚複写様式（①国税収納金整理資金納付書／②所得税徴収高計算書／③領収済通知書が実質1枚のレイアウトに統合された様式）を画面上に再現したもの。主な構成要素は以下の通り。

| ブロック | 内容 |
|---|---|
| 上部ヘッダー | 税務署名欄／税務署使用欄／整理番号欄／記入例（「¥1234567890」の数字記入見本） |
| 区分別テーブル（左） | 行見出し：俸給・給料等(01)／賞与(役員賞与を除く)(02)／日雇労務者の賃金(06)／退職手当等(07)／税理士等の報酬(08)／役員賞与(03)／同上の支払確定年月日。列見出し：支払年月日／人員／支給額／税額 |
| 納期等の区分 | 「令和　年　月」の1行入力欄（＝当該月のみを示す単月表記。[[24_帳票一覧_所得税徴収高計算書_納期特例_指示書]]では期間（自〜至）表記になる点が構造上の違い） |
| 証券受領／延納の届出欄 | チェック欄（小さいボックス2つ） |
| 住所（所在地）／電話番号／氏名（名称）欄 | 納税者（事業所）の情報記入欄 |
| 摘要欄 | フリーテキスト |
| 年末調整による不足税額(04)／超過税額(05) | 年末調整月のみ使用すると推測される欄 |
| 本税／延滞税／合計額 | 金額欄。合計額には「￥」記載欄あり |
| あて先／領収日付印 | 税務署側が使用する欄（円形の日付印スペース） |

- 罫線色（ピンク＝納付書部分、オレンジ＝計算書・領収済通知書部分）で用紙上の複写範囲を視覚的に区分している、実際の国税庁様式の配色をそのまま踏襲した表示
- 数値はすべて1マス1文字の升目（マス目）入力欄として表示される（国税庁様式特有のOCR対応レイアウト）

> 📌 **公式サポートサイトでの補足確認**（[帳票一覧の使い方](https://biz.moneyforward.com/support/payroll/guide/management02/mana03.html#choshudaka)より）：本帳票は「反映時期：給与計算・賞与計算の確定時に自動作成」「記載内容：所得税の納付金額」と説明されており、3-2節の「区分別テーブル」が給与・賞与両方の確定結果から自動集計される、という6章の推測を裏付ける。さらに重要な注意事項として、**「税理士等の報酬」欄（区分別テーブルの08区分）はシステム上で印字できず、専用用紙への転記時に手記入が必要**と明記されている。自社実装でこの帳票を再現する場合、当該欄は自動印字対象外として設計する必要がある。

## 4. データ構造（項目定義）

### 所得税徴収高計算書 項目マスタ

| 区分 | 項目 |
|---|---|
| 帳票メタ情報 | 対象年、対象月、税務署コード、整理番号 |
| 区分別支給・税額 | 俸給・給料等／賞与（役員賞与を除く）／日雇労務者の賃金／退職手当等／税理士等の報酬／役員賞与　各区分の支払年月日・人員・支給額・税額 |
| 納期情報 | 納期等の区分（対象年月＝単月） |
| 年末調整関連 | 年末調整による不足税額／超過税額 |
| 税額集計 | 本税、延滞税、合計額 |
| 納税者情報 | 住所（所在地）、電話番号、氏名（名称） |

→ 「俸給・給料等」「賞与」の支給額・税額は、当該月に確定した[[04_給与計算_設計書]]の給与計算結果（控除項目のうち「所得税」の合計値）を月次集計したものと推測される。自社実装でも、給与計算確定データから本帳票の区分別テーブルへ自動集計するロジックが必要。

## 5. デザインルール

- 帳票カードの外枠（タイトル＋右上ボタン2つ）は[[22_帳票一覧_住民税徴収額一覧表_指示書]]と共通の「帳票ビューア」パターン
- 期間選択の「年＋月」2段ドロップダウンは[[22_帳票一覧_住民税徴収額一覧表_指示書]]の月単位版と同一コンポーネントと推測され、月次で選択させる帳票共通のUIパターンとして踏襲する
- 帳票本体は国税庁様式を忠実に再現する必要があるため、他画面のような自由なテーブルデザインではなく、**用紙レイアウトを画像／固定グリッドとして再現する専用コンポーネント**として設計する（自社実装では「法定様式帳票」カテゴリとして他の一覧系帳票とは別のレンダリング方式を採用することを推奨）

## 6. 拡張・連携ポイント

- 給与計算確定時の源泉所得税集計値が、本帳票の「俸給・給料等」区分の支給額・税額に自動反映される連携が必要（[[04_給与計算_設計書]]の給与明細テーブルの「所得税」控除項目が源泉と推測）
- 賞与がある月は「賞与（役員賞与を除く）」区分にも数値が入る想定のため、[[04_給与計算_設計書]]の対象外としている「賞与計算」機能（サイドナビに別項目として存在）のデータとも連携する可能性がある
- [[24_帳票一覧_所得税徴収高計算書_納期特例_指示書]]とは同一の国税庁様式・同一の項目定義を共有しており、自社実装では帳票テンプレートを共通化し、「納期等の区分」の表示形式（単月／期間）と「年」or「年＋月」の選択UIのみを出し分ける設計が効率的
- 帳票一覧トップでは本画面は「税務署へ届出が必要な書類」というカテゴリに分類されており、同カテゴリには本画面と[[24_帳票一覧_所得税徴収高計算書_納期特例_指示書]]の2つのみが並んでいる

## 7. 個人情報保護に関する対応メモ

- 画像・PDFに記載されていた実在の会社名・住所・電話番号・税額・税務署使用欄の記入内容は、本書はもちろん今後作成するどの資料にも転記していません
- 別AIへの実装指示時も、本書の項目ラベル・様式レイアウト構造のみを渡し、実データ（金額・住所・電話番号等）は渡さないことを推奨します
- 元画像・PDFファイル自体（`帳簿一覧/所得税徴収高計算書/`フォルダ内）には納税者の住所・電話番号・会社名・金額が実データのまま記載されているため、他者と共有する際は取り扱いにご注意ください
- 国税庁様式は公開の法定様式であるため様式自体（マス目のレイアウト・項目ラベル）は転記して問題ないと判断し、本書ではレイアウト構造のみを記述しています
