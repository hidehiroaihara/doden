# 帳票一覧／給与振込一覧表 指示書

参照元：マネーフォワード クラウド給与「帳票一覧＞給与振込一覧表」画面
取得資料：画像2枚（一覧画面／支給期間セレクタ展開時）

> 🔒 **個人情報の取扱いについて**：参照元の画像には実在の会社名・従業員氏名・振込額が含まれていましたが、本書には一切転記していません。以下は画面構造・項目ラベル・UIコンポーネントのみを抽出したものです。

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | 帳票一覧＞給与振込一覧表 |
| 目的 | 指定した支給期間について、全従業員分の振込先金融機関・口座情報・振込額を一覧表示し、印刷／PDF出力する（給与振込データ作成の突合資料） |
| 主要ユーザー | 給与担当者・経理担当者 |
| 表示トリガー | [[18_帳票一覧_全体像_指示書]]の「毎月確認するもの」＞「給与振込一覧表」カード。または[[04_給与計算_設計書]]の「振込業務」ドロップダウン＞「給与振込一覧表で確認」 |

## 3. コンポーネント仕様

### 3-1. 支給期間セレクタ

| 要素 | 内容 |
|---|---|
| 表示 | 「YYYY年MM月DD日支給」＋▼ |
| 展開時 | 直近の支給期間から過去に向かって縦一列でリスト表示（本キャプチャでは直近12ヶ月分＝1年分を確認）。年をまたいだページング有無は未確認 |
| 選択 | クリックで一覧の対象期間が切り替わる（画面遷移なしのプルダウン選択と推測） |

→ [[04_給与計算_設計書]]の支給期間セレクタと機能は同じだが、本画面では「確定済み／未確定」等の視覚的区別（finalized表示）は本キャプチャでは確認できなかった（要実機確認）。

### 3-2. 帳票ヘッダー情報

| 要素 | 内容 |
|---|---|
| 帳票タイトル | 「給与振込一覧表」 |
| 出力ボタン | [印刷][PDF]（画面右上、[[21_帳票一覧_支給控除一覧表_指示書]]と共通の意匠） |
| メタ情報 | 「支給日：令和XX年XX月XX日　名称未設定」の1行表示。「名称未設定」は支給期間に付与できる名称ラベルで、未設定の場合の初期値と推測される |

### 3-3. 振込一覧テーブル

| カラム | 内容 |
|---|---|
| 振込先金融機関名 | 本キャプチャでは全行空欄（金融機関マスタ未登録の状態と推測） |
| 従業員名 | 氏名（姓・名の間にスペース） |
| 口座番号 | 本キャプチャでは全行空欄 |
| 口座名義人 | 本キャプチャでは全行空欄 |
| 振込額 | 右揃え数値、円表記 |
| 備考 | 本キャプチャでは全行「口座未登録」と表示。振込先口座がマスタ未登録の従業員に対する自動注記と推測される |
| 合計行 | テーブル最下部に全従業員の振込額合計＋対象件数（「N件」）を表示 |

→ 「備考＝口座未登録」が全行に表示されていることから、本テスト環境では従業員の口座情報マスタが未整備の状態であることが分かる。本来は[[05_従業員情報_指示書]]で確認した「支払情報」タブ（本プロジェクトでは未取得）に口座情報が登録され、その値が本帳票の「振込先金融機関名／口座番号／口座名義人」に反映される設計と推測される。

## 4. データ構造（項目定義）

### 給与振込一覧表 行データ

| 項目 | 備考 |
|---|---|
| 振込先金融機関名、口座番号、口座名義人 | 従業員マスタの口座情報（[[05_従業員情報_指示書]]の「支払情報」タブ相当、本プロジェクトでは未取得）を参照 |
| 従業員名 | 従業員マスタ参照 |
| 振込額 | [[04_給与計算_設計書]]の給与計算結果（差引合計＝「振込支給額」）を参照 |
| 備考 | 口座未登録等のステータス注記（自動生成） |
| 合計 | 振込額の合計・対象件数 |

→ 本帳票は独自データを持たず、「従業員マスタの口座情報」×「当該支給期間の給与計算結果（振込支給額）」を突合して生成される派生帳票である。自社実装でも、給与計算結果テーブルと従業員口座マスタをJOINして本帳票を都度生成するビュー的な設計にすべきで、専用のデータストアを別途持つ必要はないと考えられる。

## 5. デザインルール

- 「帳票一覧へ戻る」リンク＋支給期間セレクタのみのサイドカラムは、[[21_帳票一覧_支給控除一覧表_指示書]]の左パネルと共通のミニマルなレイアウトパターン
- テーブルは「合計行を最下部に配置」する[[04_給与計算_設計書]]の給与内訳テーブルと共通のパターンを踏襲
- [印刷][PDF]ボタンの配置（帳票タイトル行の右端）は帳票系画面共通のデザインルールと推測される

## 6. 拡張・連携ポイント

- 本帳票は[[04_給与計算_設計書]]の「振込業務」ドロップダウンからも同一画面へ遷移できる導線が確認されており（04番8章の未取得事項が本画面で解消）、自社実装でも「給与計算画面」「帳票一覧」の両方から同じ帳票画面への導線を持たせる設計を推奨
- 「備考＝口座未登録」の自動判定ロジックは、従業員マスタの口座情報が未入力の場合に自動表示されるバリデーション的な機能と推測される。自社実装でも、振込データ（FBデータ）出力前のチェック機能として、口座未登録者を本帳票やアラートで可視化する設計を推奨
- [[04_給与計算_設計書]]の「振込業務」メニューには「給与振込のFBデータ出力」という項目もあり、本帳票（一覧表示・PDF確認用）とFBデータ出力（実際の振込実行用データ）はセットの機能と推測される（FBデータ出力画面は本プロジェクトでは未取得）

> 📌 **公式サポートサイトでの補足確認**（[給与の振込方法について](https://biz.moneyforward.com/support/payroll/guide/howto-payroll/hpr04.html)、[帳票一覧の使い方](https://biz.moneyforward.com/support/payroll/guide/management02/mana03.html#furikomi)より）：給与の振込方法には次の3通りがあると明記されている。①「支払業務」画面から全銀データ形式のFBデータを出力し、利用中の銀行に取り込んで振込を実行する方法、②「給与振込サービス（みずほ銀行連携）」でクラウド給与内から直接振込を実行する方法、③「給与振込サービス（三井住友銀行連携）」で同様に直接振込する方法。上記の「給与振込のFBデータ出力」は①の「支払業務」画面の機能に相当すると推測される（記事内に本帳票＝給与振込一覧表への直接の言及はなかった）。また、給与振込一覧表そのものについては「反映時期：給与計算・賞与計算の確定時に自動作成」「記載内容：各従業員の振込金額と給与の振込先」との記載があり、3〜4章の記述と一致する。みずほ銀行連携・三井住友銀行連携という直接振込機能の存在は本プロジェクトの他資料では未確認であったため、新規情報として6章に追記した。

## 7. 個人情報保護に関する対応メモ

- 画像内の実在の会社名・従業員氏名・振込額は、本書はもちろん今後作成するどの資料にも転記していません
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造のみを渡し、実データは渡さないことを推奨します
- 元画像ファイル自体（`帳簿一覧/給与振込一覧表/`フォルダ内）には個人情報（氏名・振込額）が残存しているため、他者と共有する際は取り扱いにご注意ください
