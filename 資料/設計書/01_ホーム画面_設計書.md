# ホーム画面 設計書

参照元：マネーフォワード クラウド給与「ホーム」画面
対象範囲：ヘッダー／サイドナビ／メインコンテンツ（3カードのうち2カード）
スコープ外：右カラム全体（お知らせ／よくあるご質問／お問い合わせ先／バナー2種）、「勤怠連携・労務連携」カード

---

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | ホーム（ログイン後のトップ画面） |
| 目的 | ログイン直後にユーザーを次のアクション（初期設定／メンバー招待）へ誘導するハブ画面 |
| 主要ユーザー | 事業所の労務・人事担当者（管理者アカウント） |
| 表示トリガー | ログイン成功後の初期表示、サイドナビ「ホーム」クリック時 |

---

## 2. 画面構成（レイアウト）

```
┌─────────────────────────────────────────────────────────┐
│ Header：ロゴ / (通知アイコンは要否検討) / 事業所名▼ / ユーザー名▼   │
├───────────┬─────────────────────────────────────────────┤
│           │  H1: 🏠 ホーム                                  │
│           │                                                │
│  Side     │  ┌ Card 1：はじめに ─────────────────────┐      │
│  Nav      │  └────────────────────────────────────┘      │
│  (固定幅)  │  ┌ Card 2：メンバー管理 ───────────────────┐      │
│           │  └────────────────────────────────────┘      │
│           │ （Card 3：連携設定 は対象外のため実装しない）        │
│           │                                                │
└───────────┴─────────────────────────────────────────────┘
```

- 2カラム構成：左＝固定幅サイドナビ、右＝可変幅メインコンテンツ（右カラムの情報カードは本設計では持たない＝メインコンテンツを1カラム幅で使う）
- サイドナビは開閉可能（下部に「メニューを閉じる」）
- メインコンテンツは縦積みのカードリスト（現状2枚、拡張時は縦に追加）

---

## 3. コンポーネント仕様

### 3-1. ヘッダー

| 要素 | 内容 | 備考 |
|---|---|---|
| ロゴ＋サービス名 | 左上固定 | 自社サービス名に置換 |
| 事業所名ドロップダウン | 複数事業所切替 | 単一事業所運用なら非表示可 |
| ユーザー名ドロップダウン | ログイン中ユーザー表示、ログアウト等 | プロフィール／ログアウトのメニューを内包 |
| 通知・ヘルプアイコン | ベルアイコン／？アイコン | 本設計ではスコープ外（右カラムのお知らせと連動する機能のため） |

> 📌 **公式サポートサイトでの補足確認**（[「通知」画面の使い方](https://biz.moneyforward.com/support/payroll/guide/system-management/pa_notification.html)より）：ヘッダーのベルアイコン（通知アイコン）は、右カラムの「お知らせ」機能とは別物で、**ユーザー自身が直近に行った操作の処理結果**（帳票PDF一括作成、年末調整データのインポート、給与振込（FB）データ出力、従業員情報CSVアップロード等）を一覧確認する機能。エラー発生時は「（詳細を確認）」から詳細を確認できる。給与担当者権限を持つユーザーのみ利用可能。→ 6章の除外理由「右カラムのお知らせ・FAQ機能と連動するため」は公式情報と食い違う可能性がある（実際は自分の操作履歴確認機能）。除外の判断自体（自社ツールでは不要）は妥当と考えられるが、除外理由の記載は要修正の可能性あり。

### 3-2. サイドナビゲーション

固定幅の縦メニュー。ダーク背景＋白文字、選択中項目のみ背景色を変えてハイライト。

| # | メニュー項目 | アイコン | 遷移先（想定） |
|---|---|---|---|
| 1 | ホーム | 家 | 本画面 |
| 2 | 給与計算 | 給料袋 | 給与計算一覧 |
| 3 | 賞与計算 | トロフィー | 賞与計算一覧 |
| 4 | 支払業務 | 銀行 | 支払データ作成 |
| 5 | 従業員情報 | 人物 | 従業員マスタ |
| 6 | 基本設定 | 歯車 | 事業所基本設定 |
| 7 | 帳票一覧 | 書類 | 帳票出力一覧 |
| 8 | 連携設定 | カレンダー | 外部サービス連携（本設計ではスコープ外） |
| 9 | その他業務 | リスト | その他機能 |

フッター部：メニュー開閉トグル、運営元名、規約・ポリシーリンク群（自社向けに文言差し替え）。

**状態**
- 通常／ホバー／選択中（アクティブ）の3状態を用意
- 選択中は現在ページと連動してハイライト

### 3-3. メインコンテンツ（カード）

共通構造（カードコンポーネント）：

```
┌──────────────────────────────────┐
│ ■■ セクションラベル（濃紺帯・白文字・右端が矢印形）│
│                                    │
│  [アイコン] リンクタイトル（青文字・太字）    │
│  説明文（グレー、2行程度）              │
│  補足リンク（任意）                    │
└──────────────────────────────────┘
```

| # | セクションラベル | リンクタイトル | 説明文 | 補足リンク |
|---|---|---|---|---|
| 1 | はじめに | 初期設定チュートリアル | 説明を見ながら給与計算に必要な事業所設定を行いましょう。 | 使い方の詳細は「こちら」 |
| 2 | メンバー管理 | メンバー追加 | 従業員をログインできるようにしましょう。Web給与明細で紙の業務を減らしましょう。 | なし |

> 📌 **公式サポートサイトでの補足確認**（[従業員のログイン方法](https://biz.moneyforward.com/support/payroll/guide/login/lo01.html)、[給与担当者の設定方法](https://biz.moneyforward.com/support/payroll/guide/login/lo02.html)より）：本カード「メンバー追加」の遷移先は「メンバーの追加・管理」画面であり、そこから「従業員をメンバーに追加する」（既存従業員へのログイン権限付与）と「給与担当者を追加する」（従業員データを持たないアカウント作成）の2経路に分岐する。これは[[03_メンバー追加_設計書]]3-2章の記載と整合する一次情報が公式記事側でも確認できた。

> 📌 **公式サポートサイトでの補足確認**（[チュートリアルによる初期設定の方法](https://biz.moneyforward.com/support/payroll/guide/employee-management/em06.html)より）：Card1「初期設定チュートリアル」は給与担当者権限ユーザー向けの機能で、チュートリアルだけでは全項目を設定しきれず、詳細設定は別途「基本設定」画面で行う必要があると明記されている（[[02_初期設定チュートリアル_設計書]]参照）。

※「連携設定／勤怠連携・労務連携」カードは本設計では実装対象外（本文冒頭の指示どおり）。

## 4. データ構造（登録内容・CMS化した場合の項目）

各カードを管理画面から編集可能にする場合を想定した項目定義。

| フィールド名 | 型 | 必須 | 説明 |
|---|---|---|---|
| section_label | string | ○ | セクションラベル（例：はじめに／メンバー管理） |
| icon | string(icon key) | - | リンク先アイコン種別 |
| title | string | ○ | リンクタイトル（青文字見出し） |
| description | text | ○ | 説明文（複数行可） |
| sub_link_text | string | - | 補足リンクの文言（例：こちら） |
| sub_link_url | string(url) | - | 補足リンクの遷移先 |
| target_url | string(url) | ○ | カードクリック時の遷移先 |
| display_order | number | ○ | 表示順（縦並び順） |
| is_active | boolean | ○ | 表示ON/OFF |

将来的にお知らせ等を復活させる場合も同様のテーブル設計（news, faq）を別途用意する想定だが、今回はスコープ外。

## 5. デザインルール

### 5-1. 配色（現行UIからの読み取り・目視ベース。実装時は実データのカラーピッカーで再確認すること）

| 用途 | 色味の目安 | 備考 |
|---|---|---|
| サイドナビ背景 | ダークネイビー（#1E2A47 系） | ブランドカラーに置換可 |
| サイドナビ文字 | 白／薄いグレー | 通常時は白、非活性は薄灰 |
| カードのセクションラベル帯 | ダークネイビー（サイドナビと同系色） | 右端が矢印（台形）カット |
| リンク・見出し文字 | ブルー（#2E5AAC 系） | ヘッダーリンク、カードタイトル、補足リンク共通 |
| 本文・説明文 | ダークグレー（#333〜#555） | |
| 背景（メインコンテンツ） | 薄いグレーベージュ（#F4F3EF 系） | カード自体は白背景 |
| カード背景 | 白 | 影なし・細い罫線区切り想定 |

### 5-2. タイポグラフィ

| 用途 | サイズ目安 | ウェイト |
|---|---|---|
| 画面タイトル（H1：ホーム） | 20px前後 | 太字 |
| セクションラベル | 14px前後 | 太字・白文字 |
| カードタイトル（リンク） | 16px前後 | 太字・リンク色 |
| 説明文 | 13〜14px | 通常 |

### 5-3. スペーシング／グリッド

- サイドナビ幅：固定（PC想定 200〜220px程度）
- メインコンテンツ：左右余白を均等に確保し、カードは縦方向に一定間隔（16〜24px程度）で積む
- カード内部：セクションラベル帯とコンテンツ部の間に余白、アイコンとテキストは横並びで8px程度のギャップ

### 5-4. カードコンポーネントの共通ルール

- 1カード＝1機能導線（「何をすればよいか」を1アクションに絞る）
- セクションラベル帯は共通コンポーネント化し、ラベル文言のみ差し替え可能にする
- タイトルはリンクとして機能し、クリックで対象機能画面に遷移
- 説明文は2行以内を目安に簡潔にする
- カード数が増える場合も縦積みで拡張可能な構造にする（横並びグリッド化はしない＝現行踏襲）

### 5-5. アイコンルール

- サイドナビ・カードとも「線画（アウトライン）アイコン＋単色」で統一
- 色はテキストと同系色（ナビ＝白、カードタイトル＝ブルー）

---

## 6. 除外項目（今回のスコープ外・理由）

| 項目 | 理由 |
|---|---|
| 右カラム（お知らせ／FAQ／お問い合わせ先／バナー2種） | 本システムでは不要と判断（ユーザー指示） |
| 「連携設定／勤怠連携・労務連携」カード | 自社勤怠システムとの重複機能のため対象外（ユーザー指示） |
| ヘッダーの通知ベル・ヘルプアイコン | 右カラムのお知らせ・FAQ機能と連動するため、右カラム廃止に伴い併せて対象外 |

---

## 7. 次アクション（別AIへの実装指示のたたき台）

1. 上記レイアウト（2カラム／サイドナビ＋メインコンテンツ1カラム）でコンポーネント実装
2. カードコンポーネントを1つ作り、`section_label / icon / title / description / sub_link_text / sub_link_url / target_url` をpropsとして渡せる形にする
3. サイドナビは自社勤怠システムの既存メニュー項目にマッピングし直す（本設計の9項目は参考値であり、そのまま流用しない）
4. 配色・タイポグラフィは自社デザインシステムの既存トークンがあればそちらを優先し、本書の値はあくまで参考値とする
