# 基本設定／控除項目 指示書

参照元：マネーフォワード クラウド給与「基本設定＞控除項目」画面
取得資料：スクリーンショット3枚（一覧全体、詳細設定モーダル、計算方法ドロップダウンの展開）

> 🔒 **個人情報の取扱いについて**：参照元の画像に実在の会社名・個人名等の個人情報は含まれていませんでした（マスタ設定画面のため、数値欄はいずれも初期値のプレースホルダーです）。以下は画面構造・項目ラベル・UIコンポーネントのみを抽出したものです。

## 1. 画面概要

| 項目 | 内容 |
|---|---|
| 画面名 | 基本設定／控除項目（控除項目設定） |
| 目的 | 給与計算で使用する「控除項目」のマスタを定義する。社会保険料・税金等、法定の計算式が組み込まれた項目の有効／無効切替と、詳細設定（0円表示等）を行う |
| 主要ユーザー | 給与担当者（管理者権限） |
| 表示トリガー | サイドナビ「基本設定」→タブ「控除項目」 |

## 3. コンポーネント仕様

### 3-1. 基本設定タブ共通ナビゲーション

[[09_基本設定_支給項目_指示書]]の3-1と共通。全般／住民税／事業所／支給項目／控除項目／勤怠項目／社会保険／労働保険／年度／明細／システムの横並びタブ。

### 3-2. 控除項目テーブル（列構成）

| 列 | 内容 |
|---|---|
| 控除項目 | チェックボックス（有効／無効）＋項目名。標準項目は固定テキスト、カスタム行のみテキスト入力欄 |
| 計算方法 | 法定項目は「条件分岐＋計算式」を1本のテキストとして表示（例：「国民健康保険組合では 従業員情報で設定｜協会管掌、組合管掌では 標準報酬月額 x 保険料率」）。設定変更可能な項目のみドロップダウン（毎月手入力／従業員情報で設定）を表示 |
| 詳細設定 | ボタン。クリックでポップオーバー形式の詳細設定モーダルを開く（無効項目はグレーアウト） |
| 削除アイコン | 🗑（赤）。カスタムで追加した行（定額減税、住民税（6月分）等）にのみ表示 |

### 3-3. 標準項目の計算方法表示パターン

| パターン | 例 | 内容 |
|---|---|---|
| 条件分岐の説明文 | 健康保険料／介護保険料／子ども・子育て支援金 | 「国民健康保険組合では〜｜協会管掌、組合管掌では〜」の形式で、加入区分により計算式が自動的に切り替わることをテキストで明示 |
| 単一計算式の説明文 | 厚生年金保険料、厚生年金基金掛金、雇用保険料、所得税 | 「標準報酬月額 x 厚生年金保険料率」等、他の控除項目・支給項目の計算結果を参照する式を表示 |
| ドロップダウン選択式 | 社会保険料調整（毎月手入力）、確定拠出年金（従業員情報で設定） | ユーザーが「毎月手入力」「従業員情報で設定」を選べる項目 |
| 固定文言 | 住民税、年調過不足税額 | 「従業員情報で設定」「年末調整で算出した過不足税額(クラウド年末調整の場合「還付追徴額」)を設定」等 |
| カスタム項目 | 定額減税、住民税（6月分） | 項目名を自由入力できる追加行。計算方法はドロップダウンで選択（毎月手入力／従業員情報で設定） |

### 3-4. 詳細設定モーダル

| 要素 | 内容 |
|---|---|
| タイトル | 「（項目名） 詳細設定」（例：「健康保険料 詳細設定」） |
| チェック項目 | 「0円でも表示」の1項目のみ |
| 操作 | 「閉じる」ボタンのみ |

→ [[09_基本設定_支給項目_指示書]]の詳細設定モーダル（所得税の計算対象／社会保険の計算対象／端数処理等10項目以上）と比べて大幅に簡略化されている。控除項目は法定計算式が既に組み込まれているため、ユーザーが調整できるのは表示制御（0円でも表示）程度に限定されていると考えられる。

> 📌 **公式サポートサイトでの補足確認**（[「控除項目」の設定方法](https://biz.moneyforward.com/support/payroll/guide/setting/se12.html)より）：控除項目の詳細設定は「対象項目が0円の場合の明細表示有無を選択可能」という一般的な説明に留まっており、これは全控除項目に共通する仕様として案内されている（健康保険料以外の項目でも同一UIである可能性が高いことを示唆するが、記事内で全項目を個別列挙した確認ではない点に留意）。また、カスタム項目追加時の計算方法についても「毎月手入力」「従業員情報で設定」の2択に限定され、**「任意の計算式を設定することはできません」と明記**されている＝支給項目にあった「カスタム計算式」オプションは控除項目には存在しない。

### 3-5. 行の追加・削除

[[09_基本設定_支給項目_指示書]]の3-6と同様（＋追加ボタン、カスタム行のみ削除アイコン、画面下部固定の「保存する」ボタン）。

## 4. データ構造（項目定義）

### 控除項目マスタ（確認できた全項目）

| 区分 | 項目名 | デフォルト状態 | 計算方法の概要 |
|---|---|---|---|
| 社会保険料 | 健康保険料 | 有効 | 国保組合＝従業員情報で設定／協会・組合管掌＝標準報酬月額×保険料率 |
| 社会保険料 | 介護保険料 | 有効 | 健康保険料と同パターン |
| 社会保険料 | 子ども・子育て支援金 | 有効 | 健康保険料と同パターン |
| 社会保険料 | 厚生年金保険料 | 有効 | 標準報酬月額×厚生年金保険料率 |
| 社会保険料 | 厚生年金基金掛金 | 無効 | 標準報酬月額×厚生年金基金掛金率（厚生年金基金加入事業所向けオプション項目） |
| 社会保険料 | 社会保険料調整 | 無効 | 毎月手入力（ドロップダウンで変更可） |
| 年金 | 確定拠出年金 | 無効 | 従業員情報で設定（ドロップダウンで変更可） |
| 労働保険 | 雇用保険料 | 有効 | 労働保険の計算対象×雇用保険料率 |
| 税金 | 所得税 | 有効 | (所得税の計算対象－社会保険料合計)×所得税率 |
| 税金 | 住民税 | 有効 | 従業員情報で設定 |
| 税金 | 年調過不足税額 | 無効 | 年末調整で算出した過不足税額を設定 |
| カスタム | 定額減税 | 有効（追加済み） | 従業員情報で設定 |
| カスタム | 住民税（6月分） | 無効（追加済み・未有効化） | 従業員情報で設定 |

→ 「雇用保険料」の計算式にある「労働保険の計算対象」、「所得税」の計算式にある「所得税の計算対象」は、いずれも[[09_基本設定_支給項目_指示書]]の詳細設定モーダルにあったチェック項目（労働保険の計算対象／所得税の計算対象）と同名。**支給項目側で「対象」にチェックした金額の合計が、この控除項目の計算式にそのまま入力される**、という参照関係が明確に確認できる。

## 5. デザインルール

- 基本設定タブ共通ナビゲーション、テーブルデザイン、「保存する」金色ボタンは[[09_基本設定_支給項目_指示書]]と完全共通のコンポーネントを再利用
- 計算方法列を「説明文テキスト」として表示するパターンは、支給項目の「数式ビルダー（ドロップダウン＋数値入力の組み合わせ）」とは異なる新パターン。**ユーザーが自由に組み替えられる項目（支給項目寄り）と、法定計算式が固定されている項目（控除項目寄り）とでUIパターンを使い分ける**という設計方針が読み取れる。自社実装でも「編集可能な数式」と「固定計算ロジックの説明表示」を明確に区別したコンポーネント設計を推奨
- 詳細設定モーダルは項目の性質に応じて表示内容を可変にする設計（控除項目は「0円でも表示」のみ、支給項目は10項目以上）。モーダルコンポーネント自体は共通化しつつ、中身の設定項目リストを項目マスタ側で定義する設計が妥当

## 6. 拡張・連携ポイント

- **[[04_給与計算_設計書]]との連携**：本画面で有効化した控除項目が、給与計算画面の3カラム内訳テーブル「控除」列にそのまま反映される（[[04_給与計算_設計書]]4章で確認した「健康保険料、介護保険料、厚生年金保険料、雇用保険料、子ども・子育て拠出金、所得税、住民税」という実際の表示項目と、本画面の標準控除項目一覧が完全に一致）
- **[[09_基本設定_支給項目_指示書]]との相互参照**：「雇用保険料＝労働保険の計算対象×雇用保険料率」「所得税＝所得税の計算対象−社会保険料合計」等、控除項目の計算式は支給項目マスタ側で立てた「計算対象」フラグの集計値を入力として使用する。自社実装では、支給項目マスタに立てたフラグ（社会保険/所得税/労働保険の計算対象）を基に「合算対象の支給額を都度集計するサービス層」を設け、控除項目側の計算式はその集計値を参照する構成にする必要がある
- カスタム項目（定額減税、住民税（6月分））が既に追加されている点から、法改正（定額減税等の一時的な制度対応）や住民税の特殊な徴収タイミング（6月分の別立て徴収）にも、標準マスタとは別に「＋追加」でアドホックに対応できる拡張性を持たせていることが分かる。自社実装でも控除項目マスタは固定スキーマではなく、可変長のカスタム項目を持てるテーブル設計にする必要がある

## 7. 個人情報保護に関する対応メモ

- 本画面の参照画像には実在の会社名・個人名・金額等の個人情報は写り込んでいませんでした（マスタ設定画面のため数値欄はすべて未入力状態）
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造のみを渡すことを推奨します
- 元画像ファイル自体（`基本設定/控除項目/`フォルダ内）についても、確認した範囲では個人情報の残存は見当たりませんでしたが、共有前に念のため再確認することを推奨します

## 8. 未取得・要追加確認事項

| 項目 | 内容 |
|---|---|
| 「社会保険料調整」「確定拠出年金」の計算方法ドロップダウンの全選択肢 | 依然未確認。「毎月手入力」以外の選択肢の有無は公式サポートサイトにも記載なし |
| 各項目の詳細設定モーダルが全て「0円でも表示」のみか | 概ね解決：公式サポートサイト（[「控除項目」の設定方法](https://biz.moneyforward.com/support/payroll/guide/setting/se12.html)）でも「0円時の表示可否」のみが一般的な機能として説明されており、健康保険料以外でも同一UIである可能性が高い（ただし全項目を個別列挙した確証ではない） |
| 「＋追加」で新規カスタム項目を作成した際の計算方法選択肢の全容 | 解決：「毎月手入力」「従業員情報で設定」の2択のみで、任意の計算式（カスタム計算式）は設定できないことが公式サポートサイトで明記された |
| 控除項目にも給与区分別（月給/時給/日給/賞与）のサブタブが存在するか | 解決：存在しない。公式サポートサイトにより「控除項目は全従業員の給与・賞与に同じ項目が適用される」単一マスタであることが判明 |
| 「年調過不足税額」「厚生年金基金掛金」等、無効状態の項目を有効化した際の挙動 | 依然未確認 |
