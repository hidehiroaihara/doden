# 源泉徴収簿（帳票一覧）指示書

参照元：マネーフォワード クラウド給与「帳票一覧＞源泉徴収簿」画面
取得資料：画像2枚（一覧＋帳票左側の画面キャプチャ／帳票右側の続き部分のスクリーンショット）

> 🔒 **個人情報の取扱いについて**：参照元の画像には実在の会社名・従業員氏名・従業員番号・給与金額・税額等が含まれていましたが、本書には一切転記していません。以下は画面構造・帳票レイアウト・項目ラベルのみを抽出したものです（金額・税額等の具体的な数値は一切記載していません）。

## 4. データ構造（項目定義）

### 源泉徴収簿 月次項目

| 区分 | 項目 |
|---|---|
| 給料・手当等 | 区分、月別、支給月日、総支給金額、社会保険料等の控除額、社会保険料等控除後の給与等の金額、扶養親族等の数、算出税額、年末調整による過不足税額、差引徴収税額 |
| 賞与等 | 給料・手当等と同型項目＋税率(%) |

### 扶養控除等の申告・各種控除額 項目

| 区分 | 項目 |
|---|---|
| 親族区分 | 源泉控除対象配偶者、特定扶養親族、老人扶養親族（同居老親等／その他） |
| 障害者区分 | 一般の障害者、特別障害者、同居特別障害者（各：本人・配偶者扶／配偶者扶） |
| その他区分 | 寡婦・ひとり親、勤労学生 |
| 申告情報 | 申告の有無、申告月日（当初／追加） |
| 控除額 | 1人当たり控除額(万円)、合計控除額(万円) |

### 年末調整（年調計算）項目

| 丸数字 | 項目名 |
|---|---|
| ①③ | 給料・手当等（金額／税額） |
| ④⑥ | 賞与等（金額／税額） |
| ⑦⑧ | 計（金額／税額） |
| ⑨ | 給与所得控除後の給与等の金額 |
| ⑩ | 所得金額調整控除額 |
| ⑪ | 給与所得控除後の給与等の金額（調整控除後） |
| ⑫〜⑭ | 社会保険料等控除額（給与等からの控除分／申告による社会保険料の控除分／申告による小規模企業共済等掛金の控除分） |
| ⑮ | 生命保険料の控除額 |
| ⑯ | 地震保険料の控除額 |
| ⑰ | 配偶者（特別）控除額 |
| ⑱ | 特定親族特別控除額 |
| ⑲ | 扶養控除額及び障害者等の控除額の合計額 |
| ⑳ | 基礎控除額 |
| ㉑ | 所得控除額の合計額 |

> 📌 **公式サポートサイトでの補足確認**（[帳票一覧の使い方](https://biz.moneyforward.com/support/payroll/guide/management02/mana03.html#gensentyosyubo)、[所得税の定額減税を計算する方法](https://biz.moneyforward.com/support/payroll/guide/howto-payroll/hpr09.html)より）：源泉徴収簿は「反映時期：給与計算の確定時に自動作成」「記載内容：各従業員の1年間の給与・社会保険料・税額など」と説明されている一方、**「源泉徴収簿には左側の内容のみが反映される」という重要な注意事項が明記されている**。本書2-2節の帳票レイアウトに照らすと、「左側＝月次実績エリア（甲欄/乙欄区分・前年繰越の過不足税額・給料/賞与の月次テーブルとその計）」は給与計算確定データから自動反映される一方、「右側＝申告・年末調整エリア（扶養控除等の申告・各種控除額、年末調整の①〜㉞の積み上げ計算）」は自動反映の対象外である可能性が高いことを示唆する（記事内に右側の入力方法についての直接の記載はなく、あくまで推測。年末調整計算自体は別サービス「マネーフォワード クラウド年末調整」が担う可能性がある）。また、定額減税（所得税）の毎月の控除額は本帳票にも反映されると別記事（hpr09.html）に明記されている。

## 6. 拡張・連携ポイント

- 月次テーブルの「総支給金額」「社会保険料等の控除額」「算出税額」等は[[04_給与計算_設計書]]の給与計算結果（支給・控除・差引合計）が月ごとに集計されたものであり、給与計算確定時のデータをそのまま転記・集計する設計が必要
- 「扶養控除等の申告・各種控除額」ブロックは[[05_従業員情報_指示書]]の扶養情報カード・所得税カードの内容が反映されたものと推測され、従業員マスタとのデータ連携が前提となる
- 年末調整計算（③〜㉞）は所得税法の法定計算式に基づくため、税制改正（控除額・税率等）が発生した場合にマスタ更新だけで追随できる設計（計算式をハードコードしない）が望ましい
- 「PDFの一括作成」は対象年・フィルタ条件に合致する全従業員分をまとめて出力する機能と推測され、[[29_帳票一覧_労働者名簿_指示書]]の個別印刷とは異なる一括処理の仕組みが必要

## 7. 個人情報保護に関する対応メモ

- 画像に含まれていた実在の会社名・従業員氏名・従業員番号・住所・給与金額・税額・扶養親族情報等は、本書はもちろん今後作成するどの資料にも転記していません（金額・税額の具体的な数値は一切記載していません）
- 別AIへの実装指示時も、本書の項目ラベル・レイアウト構造・計算順序のみを渡し、実データ（金額・氏名等）は渡さないことを推奨します
- 元画像ファイル自体（`帳簿一覧/源泉徴収簿/`フォルダ内）には個人情報・金額情報が残存しているため、他者と共有する際は取り扱いにご注意ください
