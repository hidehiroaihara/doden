doden 給与システム — 保険料率・税額表・標準報酬等級の「改定時の反映方法」メモ（2026-08-17 実装分）

結論から。 料率や税額表が改定されても、原則管理画面の操作だけで反映できます（協会けんぽ料率・事業所料率セット・年度設定）。 税額表・標準報酬等級のように頻度が低く全国共通のものは、年度データを1回追加すれば全社に効きます。 いずれも外部APIは不要で、国が公表する公開データ（PDF/Excel）を取り込む方式です。

プロジェクト直下（/Applications/MAMP/htdocs/laravel/doden）で実行します。読み取り専用です。料率・過去給与は変わりません。

2つの大原則

原則1: 追加はするが、過去は編集しない。
料率・税額表・等級表はすべて「適用開始日（effective_from）」を持ちます。改定時は 新しい適用開始日の行を追加してください。既存（過去）の行を書き換えると、当時の給与を再計算した際の根拠が失われます。
原則2: 計算時に「使った値」を明細へ焼き付ける（スナップショット）。
給与計算を実行すると、その時点の料率セットID・各保険料率・標準報酬月額・等級・税額表区分・扶養数・所得税マスタの識別子を 給与明細（payslips）へ保存します。あとでマスタを直しても、確定済み明細の内容と表示は変わりません。

重要（数値の正確性）： 同梱している料率・税額表・等級表は「実装時点の公表値」です。 本番運用の前に、対象年度の官報・協会けんぽの公表値と必ず突合してください（公式データ入手先参照）。

過去を塗り替えない仕組み（3層）

  • ① 適用期間：料率・税額表・等級表は支給日で「当時の行」を引く。新年度は追加、過去は不変。
  • ② 明細スナップショット：計算実行時に、使った料率セットID・各料率・標準報酬・等級・税額表区分・扶養数・所得税マスタ識別子を payslips に保存。PDF/画面の関連情報もこのスナップショットを優先表示。
  • ③ 確定ロック：確定（finalized）バッチは再計算・編集不可。
唯一の注意点：確定解除→再計算。 確定を解除して再計算すると、その時点の（＝最新の）マスタが適用され、過去の内容が上書きされます。 当時の内容を保つ必要がある場合は、再計算せずに確定し直してください（画面にも警告を表示します）。

運用者（管理画面のみ）でできる更新

プログラム変更なしで実施できる、日常運用の更新です。

  • 事業所の保険料率の改定（新年度の料率セット追加＋協会けんぽ反映）→ 事業所の料率セット
  • 都道府県が変わった／料率を当てはめ直したい → 協会けんぽ料率
  • 事業所の業種変更に伴う労災・雇用料率 → 労災・雇用保険
  • 年度（休日・所定労働時間）の切替 → 年度設定
  • 個々人の介護該当・扶養親族数の調整 → 介護保険・扶養

開発者（データ追加）でおこなう更新

全国共通で頻度が低いもの（税額表・等級表・協会けんぽ全県料率）は、Seederに新年度データを追記して1回流します。既存行は消さず、新しい effective_from を追加します。

# 1. LegalMasterSeeder.php に新年度の行を追記（effective_from を新年度に）
# 2. マイグレーション適用（新規テーブルがある場合のみ）
php artisan migrate

# 3. 法定マスタだけ流し込む（冪等：何度実行してもOK）
php artisan db:seed --class=LegalMasterSeeder

# 4. 反映確認（Excelで全保険をタブ分け出力）
php artisan payroll:rates --xlsx

# 5. 現在と新年度の差分（日付は実値に合わせる）
php artisan payroll:rates --date=2026-04-01 --compare=2027-03-01
LegalMasterSeeder は updateOrCreate（種別＋等級＋適用開始日 などをキー）で冪等です。 本番では migrate:fresh は使わないでください（全データが消えます）。追加シードのみ流します。

協会けんぽ 都道府県別料率（健康・介護）

年度改定を反映する（開発→運用）

  1. database/seeders/LegalMasterSeeder.php の seedKyokaiKenpoRates() に、新年度の $from（例 '2025-03-01'）と47都道府県の健保料率・介護料率(‰・総額)を追記。
  2. php artisan db:seed --class=LegalMasterSeeder を実行（旧年度行は残り、新年度行が増える）。確認は コマンド一覧 の --xlsx / --compare。
  3. 管理画面＞基本設定＞社会保険タブで、対象事業所に新しい料率セット（新年度の effective_from）を追加。
  4. その料率セットの「都道府県料率を反映」ボタンを押す。健保・介護（都道府県別）＋厚年・拠出金（全国一律の標準値）が自動セットされる。
  5. 表示された料率を確認して保存。
「都道府県料率を反映」は、事業所の健康保険の種類が「協会けんぽ」かつ都道府県が設定済みのときに有効です。組合健保は組合の料額表を手入力してください。

事業所の保険料率セット（実際に計算で使う値）

給与計算は「支給日に有効な事業所の料率セット」を参照します。改定は上書きではなく新セット追加です。

  1. 基本設定＞社会保険タブ＞「料率セットを追加」で、事業所・名称・適用開始日（例 4/1）を入力して作成。
  2. 協会けんぽなら「都道府県料率を反映」。組合健保等は各料率を千分率で手入力。
  3. 厚生年金は全国一律（総額183.00‰＝労使折半で各91.50‰）。子ども・子育て拠出金は事業主のみ（現行3.60‰）。
  4. 保存。以後、その適用開始日以降の給与計算に自動適用される。
料率は画面上千分率（/1,000）で表示・保存します（健保 4.99% → 49.9）。%と混同しないでください。

標準報酬月額 等級表

健保50等級・厚年32等級を 2020-09-01 適用で全件同梱済み。等級表自体の改定はまれ（厚年上限追加など）です。

  • 等級表の改定時（開発）： LegalMasterSeeder::seedStandardRewardGrades() に新しい $from で全等級を追記 → db:seed --class=LegalMasterSeeder。
  • 従業員の標準報酬（運用）： 従業員情報＞給与情報で「標準報酬月額」を入力すると、対象日基準で等級が自動解決されます。定時決定（毎年7月）・随時改定の際に更新してください。

源泉所得税（月額）・賞与の算出率

甲欄/乙欄の係数を income_tax_brackets / bonus_tax_rate_brackets に適用期間つきで保持。マスタ未投入期間は内蔵既定へ自動フォールバックします。

  1. LegalMasterSeeder の seedIncomeTaxBrackets() / seedBonusTaxBrackets() に、新年度の $from と係数を追記。
  2. php artisan db:seed --class=LegalMasterSeeder。
  3. 過去の支給日は旧行、改定日以降は新行を自動参照（明細スナップショットに income_tax_source を記録）。
月次は「電子計算機による源泉徴収税額の計算（電算機特例）」の係数方式を採用しています。国税庁の「月額表」や年末調整とは端数処理で数円差が出る場合があります。厳密一致が要る場合は係数を年度の告示値へ差し替えてください。

労災保険・雇用保険（業種別料率）

  • 料率の改定（開発）： app/Support/LaborInsuranceRates.php の業種プリセット（千分率）を更新。
  • 反映（運用）： 事業所編集で労災の業種・雇用の事業種類を選択して保存すると、最新の料率セットの accident / employment に自動セットされます。
  • 雇用保険（従業員負担）は「労働保険の計算対象」に料率を掛けて自動計算。労災は事業主負担のみ（従業員控除0）。

年度設定（休日・所定労働時間）

基本設定＞年度タブで年度ごとに休日・独自休日・1日の所定労働時間・月平均日数を管理します。給与計算は支給日の年度設定を優先参照します。新年度は新しい年度を追加してください（過去年度は保持）。直リンク: /admin/payroll/settings#fiscal_year

介護保険の該当・扶養親族数

  • 介護保険該当： 生年月日から満40〜64歳を計算時に自動判定（40歳到達月〜65歳到達月の前月）。従業員情報＞給与情報の「介護保険該当」で 自動判定／対象にする／対象外にする を選べます（既定＝自動）。
  • 扶養親族等の数： 従業員情報の入力値を優先。未入力（0）の場合は、扶養親族（所得税対象）の登録件数から自動集計します。
